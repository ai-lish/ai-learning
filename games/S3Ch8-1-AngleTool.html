為什麼量角器顯示的就是仰角 / 俯角？

核心事實

  • 水瓶始終保持水平（水面永遠與地面平行）
  • 重垂線永遠垂直向下（受重力影響）
  • 水瓶 ⟂ 重垂線，兩者永遠成 90°
  • 吸管（視線）與量角器是同一條線，一起旋轉
  • 量角器顯示的角度，就是吸管與重垂線的夾角

結論

  • 仰角 = 吸管向上，與重垂線（垂直）的夾角
  • 俯角 = 吸管向下，與重垂線（垂直）的夾角
  • 仰角 + 俯角 + 水平線三者互補，總和為 90°
  1. 吸管水平時，與垂直重垂線夾角 = 90°，量角器讀數 = 0°
  2. 吸管向上傾斜，夾角變小，量角器讀數變大 → 仰角
  3. 吸管向下傾斜，夾角變大，量角器讀數變小（但標示為俯角）
  4. 吸管豎直向上，與重垂線平行，量角器讀數 = 90°（仰角）
  5. 吸管豎直向下，量角器讀數 = 0°（俯角）
