為什麼量角器顯示的就是仰角 / 俯角？

核心幾何事實

  • 吸管是半圓量角器的直徑，兩端固定在圓周上
  • 吸管水平時，與重垂線（垂直）夾角 = 90°
  • 半圓量角器的弧刻度：中央底部 = 0°，兩端 = 90°
  • 因此吸管水平時，量角器讀數 = 90° − 90° = 0°
  • 吸管向上傾斜，與重垂線夾角變小 → 量角器讀數變大 → 仰角
  • 吸管向下傾斜，與重垂線夾角變大 → 量角器讀數變小（標示為俯角）

為什麼水平 ⟂ 垂直 = 90°？

  • 想像一間長方形房間：地面是水平線，牆壁是垂直線
  • 地面與牆壁永遠成 90°（直角）
  • 水瓶的水面 = 水平參考，重垂線 = 垂直參考
  • 兩者始終垂直，與吸管傾斜無關
  1. 吸管水平時，與重垂線夾角 = 90°，量角器讀數 = 0°
  2. 吸管向上 45°，與重垂線夾角 = 45°，量角器讀數 = 45°（仰角）
  3. 吸管向下 30°，與重垂線夾角 = 120°，量角器讀數 = 30°（俯角）
  4. 吸管豎直向上，與重垂線平行，量角器讀數 = 90°（最大仰角）
