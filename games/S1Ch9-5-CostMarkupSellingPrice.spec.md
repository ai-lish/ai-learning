## 3. 動態題目系統（6種題型）

### 題型邏輯

| Type | 題型名稱 | 給定 | 計算 | 公式 |
|------|---------|------|------|------|
| 1 | 標價→售價（折扣） | 標價、折扣% | 售價 | 售價 = 標價 × (1 - 折扣%) |
| 2 | 成本→標價（利潤率） | 成本、利潤率% | 標價 | 標價 = 成本 / (1 - 利潤率%) |
| 3 | 標價→成本（折扣+利潤） | 標價、折扣%、利潤率% | 成本 | 成本 = 標價 × (1-折扣%) / (1+利潤率%) |
| 4 | 成本+售價→利潤/虧蝕 | 成本、售價 | 利潤/虧蝕 | 利潤 = 售價 - 成本 |
| 5 | 成本→售價（利潤率+折扣） | 成本、利潤率%、折扣% | 售價 | 標價 = 成本/(1-利潤率%), 售價 = 標價×(1-折扣%) |
| 6 | 成本→標價（利潤$） | 成本、標價-$、利潤$ | 利潤率% | 利潤 = 標價 - 成本, 利潤率 = 利潤/標價 |

### 變數關係（來自 GeoGebra 實測）

```
A = 成本 (Cost)
B = 標價 (Marked Price)
C = 售價 (Selling Price)
discount = 折扣百分比
Percent = 利潤百分比
Percentvalue = 利潤（小數）
selectedpercent = 當前選擇的百分比值
```

### 動態生成規則

每題隨機生成以下組合（確保現實可行）：

```
成本 (A):     1000 - 9000（整數，百位/千位）
標價 (B):     A × (1 + 利潤率%)，確保 ≥ 成本
折扣:         10% - 80%（整數）
售價 (C):     B × (1 - 折扣%)
利潤:         C - A（可正可負）
```

## 5. 題目區互動設計

### 上半部分（視覺理解區）

每題顯示 2-3 個顏色格，根據 Type 決定顯示邊個：

| Type | 顯示格 | 問號格 |
|------|--------|--------|
| 1 | 標價(B)、售價(C) | - |
| 2 | 成本(A)、標價(B) | - |
| 3 | 標價(B) | 成本(A) |
| 4 | 成本(A)、售價(C) | 利潤/虧蝕 |
| 5 | 成本(A) | 標價(B)、售價(C) |
| 6 | 成本(A)、標價(B) | 利潤率% |

每個格：
- 圓角矩形，顏色填充
- 頂部標籤（如「成本」）
- 內部顯示數字或「?」
- 動畫：格子上有幾何圖形裝飾

### 下半部分（計算區）

**黃金公式按鈕**（位於右側中部）：
- 每次題目根據 Type 動態生成 2-4 個公式按鈕
- 公式按鈕格式：`[ A ]`、`[ B ]`、`[ C ]`、`[ % ]`、`[ + ]`、`[ - ]`、`[ × ]`、`[ ÷ ]`、`[ ( ]`、`[ ) ]`
- 點擊公式按鈕：將符號/數字加入計算表達式
- 按下狀態：稍微變暗

**計算表達式顯示**：
- 顯示學生當前輸入的表達式，如 `B - C`
- 自動計算結果（如 `B - C = 2940`）
- 表達式下方實時顯示計算結果

### 底部答案區

根據 Type 顯示對應輸入框：

| Type | 答案輸入 |
|------|---------|
| 1 | 折扣% |
| 2 | 利潤率% |
| 3 | 成本 |
| 4 | 利潤 或 虧蝕 |
| 5 | 標價 和 售價 |
| 6 | 利潤率% |

每個答案：
- 大輸入框（`100px` 寬）
- 右側 `核對` 按鈕
- 答案正確：整行變綠 + `✓` + 分數+1
- 答案錯誤：整行變紅 + `✗` + 分數不變
