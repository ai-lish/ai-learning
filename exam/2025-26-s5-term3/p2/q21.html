第 21 題

考核重點：軌跡識別 — 點與直線距離
若 \(P\) 為直角坐標平面上的一動點使得 \(P\) 與直線 \(y=-4\) 間之距離等於原點與點 \((0,1)\) 之距離，則 \(P\) 的軌跡為
  1. A一個圓
  2. B一條直線
  3. C一條拋物線
  4. D一對平行線

答案

D（一對平行線）

詳解

考核重點

軌跡識別 — 點與直線距離

解題步驟

  1. 原點與 \((0, 1)\) 距離 = \(|0 - 1| = 1\)
  2. P 與直線 \(y = -4\) 距離 = 1：\(\dfrac{|y - (-4)|}{1} = |y + 4| = 1\)
  3. \(|y + 4| = 1\) → \(y + 4 = 1\) 或 \(y + 4 = -1\)
  4. 即 \(y = -3\) 或 \(y = -5\)（兩條水平線，平行）

陷阱分析

A. 一個圓：軌跡 = P 同固定點距離固定（但本題係固定線）→ 完全搞錯軌跡類型

B. 一條直線：只解咗 \(|y+4|=1\) 其中一個（漏絕對值第二個解）

C. 一條拋物線：拋物線定義需同時涉及點同線（focus + directrix）→ 本題只有線冇點

D. 一對平行線：✅ 對

秒殺技巧

「點到線距離 = 常數 → 一對平行線；點到點距離 = 常數 → 圓；點到點 = 點到線 → 拋物線」— 記呢個 Venn diagram。
