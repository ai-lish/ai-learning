第 39 題

考核重點：正弦公式（SSA ambiguous case + 銳角條件揀解）
圖中，\(\angle CAB\) 為一銳角。求 \(\angle ABC\) 準確至最接近的度。
  1. A\(13^\circ\)
  2. B\(33^\circ\)
  3. C\(127^\circ\)
  4. D\(147^\circ\)

答案

D（147°）

詳解

考核重點

正弦公式（SSA ambiguous case + 銳角條件揀解）

解題步驟

（VLM 確認：\(AB = 5\), \(AC = 8\), \(\angle ACB = 20°\)）

  1. 設 \(\angle ABC = \theta\)
  2. Sine rule: \(\dfrac{AB}{\sin\angle ACB} = \dfrac{AC}{\sin\angle ABC}\)
  3. \(\dfrac{5}{\sin 20°} = \dfrac{8}{\sin\theta}\)
  4. \(\sin\theta = \dfrac{8 \sin 20°}{5} = \dfrac{8 \times 0.342}{5} = \dfrac{2.736}{5} = 0.5472\)
  5. 正弦有兩個可能解：\(\theta = \arcsin(0.5472) \approx 33.2°\) 或 \(\theta = 180° - 33.2° = 146.8°\)。
  6. 題目講 \(\angle CAB\) 是銳角。若 \(\angle ABC = 33.2°\)，則 \(\angle CAB = 180° - 20° - 33.2° = 126.8°\)，不是銳角。
  7. 因此取 obtuse 解：\(\angle ABC = 146.8° \approx 147°\) ✓

> 13° 其實係 \(\angle CAB \approx 180° - 20° - 146.8° = 13.2°\)，不是題目要求嘅 \(\angle ABC\)。

> ⚠️ 邊長數值（\(AB=5\), \(AC=8\), \(\angle ACB=20°\)）須對 2526 PDF 圖核實（figure UNVERIFIED，但 math 3-LLM verified）。

陷阱分析

（正弦公式雙解）

A. 13°：計咗 \(\angle CAB\)，但題目問 \(\angle ABC\)

B. 33°：sine rule 嘅 acute 解，但會令 \(\angle CAB=126.8°\)，違反銳角條件

C. 127°：錯誤 supplement / 邊角配對

D. 147°：✅ 對（sine rule obtuse 解，且 \(\angle CAB\) 為銳角）

秒殺技巧

Sine rule 有 SSA ambiguous case；用「\(\angle CAB\) 銳角」去揀 \(\angle ABC\) 嘅 obtuse 解。
