## Q1-9 (Section A part 1)

## 第 1 題　答案：B

【考核重點】指數律（負指數、零指數、指數乘除）

【解題步驟】
1. 寫出算式：
   $\dfrac{8x^{-3}y^{2}}{(-2xy^{-1})^{2}}$
2. 先處理分母平方：
   $(-2xy^{-1})^{2} = (-2)^{2}\cdot x^{2}\cdot (y^{-1})^{2} = 4x^{2}y^{-2}$
3. 代入：
   $\dfrac{8x^{-3}y^{2}}{4x^{2}y^{-2}} = \dfrac{8}{4}\cdot x^{-3-2}\cdot y^{2-(-2)} = 2x^{-5}y^{4}$
4. 將負指數移到分母：
   $= \dfrac{2y^{4}}{x^{5}}$

【陷阱分析】
- A. $-\dfrac{2y^{4}}{x^{5}}$：漏咗負號來源（分母平方後已變正）
- C. $\dfrac{y^{4}}{-2x^{5}}$：分子指數 $8/4$ 計成 1，漏寫常數
- D. $\dfrac{1}{-2x^{6}y}$：分子誤當 $(2x)^{-3}$ 拆開

【秒殺技巧】記住口訣「同底相乘指數相加、同底相除指數相減」；負指數 $\Rightarrow$ 倒數。

## 第 2 題　答案：A

【考核重點】因式分解 — 配對分組 / 提取公因式

【解題步驟】
1. 原式：$x^{2}-y^{2}-2kx+2ky$
2. 兩兩分組：
   $(x^{2}-y^{2}) + (-2kx+2ky)$
3. 第一組用平方差：$x^{2}-y^{2}=(x-y)(x+y)$
4. 第二組提取 $-2k$：$-2kx+2ky = -2k(x-y)$
5. 兩組都有 $(x-y)$，再提取：
   $(x-y)(x+y) - 2k(x-y) = (x-y)\big[(x+y)-2k\big] = (x-y)(x+y-2k)$

【陷阱分析】
- B. $(x-y)(x+y+2k)$：第二組提取 $+2k$ 漏咗負號
- C. $(x+y)(x-y-2k)$：配對方向錯誤（應該係 $x-y$ 提頭）
- D. $(x+y)(x-y+2k)$：兩個錯誤同時犯

【秒殺技巧】分組前提係兩組都有**同一個二項式因子**；本題 $x^{2}-y^{2}$ 一定係 $(x-y)(x+y)$，所以 $x-y$ 必為外因子。

## 第 3 題　答案：A

【考核重點】恆等式 (Identity) — 比較係數

【解題步驟】
1. 展開右邊：$(x-5)(x+3) = x^{2} + 3x - 5x - 15 = x^{2} - 2x - 15$
2. 展開左邊：$x^{2} + a(x-2) + b = x^{2} + ax - 2a + b$
3. 兩邊係數逐一比較：
   - $x$ 項：$a = -2$
   - 常數項：$-2a + b = -15$
4. 代入 $a=-2$：$-2(-2)+b = -15 \Rightarrow 4+b=-15 \Rightarrow b=-19$

【陷阱分析】
- B. $b=-15$：誤以為右邊常數直接係 $b$
- C. $b=-11$：用 $-2a + b = -15$ 算成 $2a + b = -15$
- D. $b=1$：可能用 $a-b=-15$ 計（混淆 $a$ 同 $b$ 角色）

【秒殺技巧】遇到 identity 題，**展開兩邊、對齊同次項係數**就一定做到。

## 第 4 題　答案：D（只有 II 及 III）

【考核重點】三角形全等條件 (SSS / SAS / ASA / AAS / RHS)

【解題步驟】
1. 判斷每對三角形用咩資料：
   - **I**：兩邊 + 一非夾角（SSA）— 三角形「不一定」全等（ambiguous case，俗稱「測不準的角」）
   - **II**：兩邊 + 夾角 SAS — 必全等 ✓
   - **III**：兩角 + 對邊 AAS — 必全等 ✓
2. 只有 II 同 III 必為全等。

【陷阱分析】
- A. 只有 III：忽略 II 嘅 SAS
- B. 只有 I 及 II：以為 SSA 都得
- C. 只有 I 及 III：以為 SSA 都得但漏 SAS

【秒殺技巧】記「**SSA 例外**」：兩邊 + 非夾角未必全等（除非係直角三角形變 RHS）。

> ⚠️ 此題需對照試題原圖核對邊角標示；本解答依標準答案 D 推斷。

## 第 5 題　答案：A

【考核重點】代數式 — 移項整理

【解題步驟】
1. 原式：$\dfrac{ab}{a-b} = 2$
2. Cross-multiply：$ab = 2(a-b)$
3. 展開右邊：$ab = 2a - 2b$
4. 將含 $b$ 嘅項移到左邊：$ab + 2b = 2a$
5. 左邊提取 $b$：$b(a+2) = 2a$
6. 兩邊除以 $(a+2)$：$b = \dfrac{2a}{a+2}$

【陷阱分析】
- B. $\dfrac{a}{a+1}$：分子漏咗 2
- C. $\dfrac{a+2}{2a}$：上下倒轉
- D. $\dfrac{2a+1}{a}$：漏咗 $+2$ 因子

【秒殺技巧】由答案反推 — A 嘅分母 $a+2$ 提示 $b$ 嘅分母應該係 $a+2$；再 cross-check 一次即可確認。

## 第 6 題　答案：C（$a = -2$ 或 $a = 2$）

【考核重點】二次方程 — 二重根條件（判別式 $\Delta = 0$）

【解題步驟】
1. 改寫成標準形式：$x^{2} + ax = -1 \;\Rightarrow\; x^{2} + ax + 1 = 0$
2. 二重根條件：判別式 $\Delta = 0$
   $\Delta = b^{2} - 4ac = a^{2} - 4(1)(1) = 0$
3. 解：$a^{2} = 4 \;\Rightarrow\; a = \pm 2$
4. 即 $a = -2$ 或 $a = 2$

【陷阱分析】
- A. $a=-1$：可能誤以為 $\Delta = 1$
- B. $a=2$：只攞正根，漏負根
- D. $0$ 或 $4$：可能把 $a$ 當根直接代入

【秒殺技巧】「**二重根 = 判別式 = 0**」係核心；切記 $\Delta$ 公式 $b^{2}-4ac$ 嘅 $b$ 係 $x$ 一次項嘅係數，唔好攞錯。

## 第 7 題　答案：B（$y = 2$）

【考核重點】聯立二元一次方程 — 連等式

【解題步驟】
1. 由 $2x - y = 3x + y = -10$，拆成兩個方程：
   $\begin{cases} 2x - y = -10 \\ 3x + y = -10 \end{cases}$
2. 兩式相加（$y$ 自動消）：$(2x-y)+(3x+y) = -10 + (-10)$
   $\Rightarrow 5x = -20 \;\Rightarrow\; x = -4$
3. 代入其中一式：$2(-4) - y = -10 \;\Rightarrow\; -8 - y = -10 \;\Rightarrow\; y = 2$

【陷阱分析】
- A. $y=4$：加錯號
- C. $y=-2$：可能將 $2x-y=10$ 算成 $-2x-y=-10$
- D. $y=-4$：混淆 $x$ 同 $y$ 嘅值

【秒殺技巧】連等式**兩邊相加消元**最快 — 留意題目問邊個變數，唔好將 $x$ 當 $y$ 寫。

## 第 8 題　答案：D（$3 215）

【考核重點】複利息 — 每季一結

【解題步驟】
1. 設定：
   本金 $P = 20\,000$，年利率 $R = 5\% = 0.05$，年期 $T = 3$ 年，每年結算 $k = 4$ 次
2. 季利率 $r = \dfrac{R}{k} = \dfrac{0.05}{4} = 0.0125$
3. 總期數 $n = kT = 4 \times 3 = 12$
4. 本利和公式：$A = P(1+r)^{n} = 20\,000 \times (1.0125)^{12}$
5. 計算 $(1.0125)^{12}$：
   - $(1.0125)^{2} = 1.02515625$
   - $(1.0125)^{4} = (1.02515625)^{2} \approx 1.05094534$
   - $(1.0125)^{8} \approx 1.10448674$
   - $(1.0125)^{12} = (1.0125)^{8} \times (1.0125)^{4} \approx 1.16075452$
6. $A = 20\,000 \times 1.16075452 \approx 23\,215.09$
7. 利息 $I = A - P \approx 3\,215.09 \approx \$3\,215$（準確至最接近的元）

【陷阱分析】
- A. $\$759$：可能當半年結算 ($n=6$)
- B. $\$3\,153$：可能當月結算 ($n=36$)
- C. $\$3\,208$：可能漏計一兩期複利

【秒殺技巧】記公式 $A = P\left(1+\dfrac{R}{k}\right)^{kT}$；**留意係「每季」即 $k=4$**，唔好當 $k=1$ 用錯年利率。

## 第 9 題　答案：C（$x \le -2$ 或 $x > 4$）

【考核重點】一元一次不等式 — 邏輯「或」

【解題步驟】
1. 拆解成兩條不等式：
   $\begin{cases} 15 - 3x < 3 & \text{(I)} \\ 5 + 2x \le 1 & \text{(II)} \end{cases}$
2. 解 (I)：$15 - 3x < 3 \;\Rightarrow\; -3x < -12 \;\Rightarrow\; x > 4$
   （兩邊除 $-3$ 要**反轉不等號**）
3. 解 (II)：$5 + 2x \le 1 \;\Rightarrow\; 2x \le -4 \;\Rightarrow\; x \le -2$
4. 「或」取聯集：$x \le -2$ 或 $x > 4$

【陷阱分析】
- A. $x \le -2$：只解咗 (II)
- B. $x < 4$：符號錯（$\le$ 變 $<$、$>$ 變 $<$）
- D. 沒有實根：將「或」當「且」解

【秒殺技巧】中文邏輯「**或 / OR**」對應 set union（兩邊都收）；「**且 / AND**」先要小心取交集。乘除負數一定要反轉符號。

## 第 10 題 答案：D（2566）

【考核重點】誤差 / 顯著位數 + 載貨量計算

【解題步驟】（VLM 確認真實條件）
1. 貨船載貨量 500 kg，準確至最接近 kg → $499.5 \leq M < 500.5$ kg

3. **最多包數** = $\left\lfloor\dfrac{\text{載貨上限}}{\text{單包下限}}\right\rfloor = \left\lfloor\dfrac{500.5}{0.195}\right\rfloor$

- C. 2500：$500/0.2$ 冇 ± 處理

## 第 11 題 答案：A（27.9 平方米）

【考核重點】扇形面積 + 弧度轉換

【解題步驟】（VLM 確認真實值：$r = 8$ m, $\theta = 50°$）
1. 扇形面積公式：$A = \dfrac{1}{2}r^{2}\theta$（$\theta$ 用弧度）
2. $\theta_{\text{rad}} = 50° \times \dfrac{\pi}{180} = \dfrac{5\pi}{18} \approx 0.8727$ rad
3. $A = \dfrac{1}{2} \times 8^{2} \times 0.8727 = 32 \times 0.8727 = 27.93 \approx 27.9$ 平方米 ✓

【陷阱分析】
- A. 27.9：✅ 對
- B. 23.0：可能用 $A = \dfrac{1}{2}r^{2}\theta \cdot \dfrac{1}{2}$ 重複 × ½... 唔對，23.0 比較似 $A = 8 \times 8 \times \dfrac{50}{360} \times \pi = 27.93$ 用近似... 唔明成因
- C. 6.98：可能 $r = 4$（將直徑當半徑嘅一半，即讀成 4 m），$\dfrac{1}{2} \times 4^{2} \times 0.8727 = 6.98$ ✓
- D. 3.49：可能 $r = 4$ 同時 $\theta = 25°$（半徑一半 + 角一半），$\dfrac{1}{2} \times 16 \times 0.4363 = 3.49$ ✓

【秒殺技巧】**先寫 $\theta_{\text{rad}} = \theta° \times \pi/180$**，再用 $A = \frac{1}{2}r^2\theta$；C/D 嘅成因係「直徑當半徑」嘅 common mistake。

## 第 12 題　答案：C（$\dfrac{y}{z} + \dfrac{z}{x}$）

【考核重點】三角比 — 對邊/鄰邊/斜邊 + 倒數運用

【解題步驟】
1. 設三角形入面：$x$ = 對邊（opposite $\theta$）、$y$ = 鄰邊（adjacent $\theta$）、$z$ = 斜邊（hypotenuse）
2. $\cos\theta = \dfrac{y}{z}$
3. $\sin\theta = \dfrac{x}{z} \;\Rightarrow\; \dfrac{1}{\sin\theta} = \dfrac{z}{x}$
4. 相加：$\cos\theta + \dfrac{1}{\sin\theta} = \dfrac{y}{z} + \dfrac{z}{x}$

【陷阱分析】
- A. $\dfrac{x+y}{z}$：$\cos$ 變 $\sin$ 搞混
- B. $\dfrac{x}{z} + \dfrac{z}{y}$：$\cos$ 變 $\sin$、$\sin$ 變 $\cos$
- D. $\dfrac{z}{x} + \dfrac{z}{y}$：分子全用 $z$

【秒殺技巧】記口訣「**對斜 cos、斜對 sin**」（對邊/斜邊 = cos，斜邊/對邊 = 1/sin）；先畫右角三角形標邊再列式。⚠️ 依原圖核實 $x/y/z$ 標示。

## 第 13 題　答案：D（$-15$）

【考核重點】餘數定理 (Remainder Theorem) + 先求常數

【解題步驟】
1. 用 $g(2) = 0$ 求 $k$：$g(2) = 2(2)^{3} - (2)^{2} + k = 12 + k = 0 \Rightarrow k = -12$
2. $g(x) = 2x^{3} - x^{2} - 12$
3. 餘數定理：$g(x) \div (x+1)$ 嘅餘數 $= g(-1)$（**代入 $x = -1$**）
4. $g(-1) = 2(-1)^{3} - (-1)^{2} - 12 = -2 - 1 - 12 = -15$

【陷阱分析】
- A. 13 = $g(2) = 12 + k = 0$（用 $g(2)$ 當餘數，但 $g(2)=0$ 唔係 13；呢個數字可能來自 $(2)^{3} - (2)^{2} + 13$ 之類錯誤）
- B. 9 = $g(2) - 3$：可能 $k$ 算成 $-9$（$12 + k = 3$ 算成 $k = -9$）
- C. $-12 = k$：混淆常數項 $k$ 與餘數

【秒殺技巧】「$g(x) \div (x - a)$ 餘數 $= g(a)$」— 記住代 $x = a$（唔係 $-a$）；本題除 $(x+1)$ 即 $a = -1$。

## 第 14 題　答案：B（$\dfrac{z\sqrt{y}}{x}$）

【考核重點】正變 / 反變 — 寫出 $z$ 嘅 formula

【解題步驟】
1. $z$ 隨 $x$ 正變：$z = k_{1}\cdot x$
2. $z$ 隨 $\sqrt{y}$ 反變：$z = \dfrac{k_{2}}{\sqrt{y}}$
3. 結合：$z = k\cdot\dfrac{x}{\sqrt{y}}$
4. 移項：$\dfrac{z\sqrt{y}}{x} = k$，必為常數

【陷阱分析】
- A. $xz\sqrt{y}$：完全冇處理反變 → $z\sqrt{y} = k x \Rightarrow z\sqrt{y}/x = k$（但 A 冇除以 $x$）
- C. $\dfrac{xz}{y}$：$\sqrt{y}$ 變 $y$（差咗個根號）→ $z = k \cdot \dfrac{x}{y} \Rightarrow \dfrac{zy}{x} = k$（多咗 $y$ 少咗 $\sqrt{y}$）
- D. $\dfrac{1}{xz\sqrt{y}}$：分子分母倒轉 → $xz\sqrt{y} = 1/k$（但呢個唔係常數，除非 $k$ 特殊）

【秒殺技巧】「正變放分子、反變放分母」— 寫出 $z = k \cdot \dfrac{x}{\sqrt{y}}$ 後，隔離 $k$ 嗰邊就係答案。

## 第 16 題　答案：A（$-4$）

【考核重點】函數值計算 — 奇偶項抵消

【解題步驟】
1. $f(2) = 3(2)^{2} - 2 - k = 10 - k$
2. $f(-2) = 3(-2)^{2} - (-2) - k = 12 + 2 - k = 14 - k$
3. $f(2) - f(-2) = (10 - k) - (14 - k) = -4$

【陷阱分析】（v2 補成因）
- B. $-k$：$f(2) - f(-2) = (10-k) - (12 - k)$ 漏算 $(-2)$ 一次項變號 → $10 - k - 12 + k = -2$，但 $k$ 抵消成 0。$f(2) - f(-2) = -k$ 暗示誤用 $f(2) = 10 - k$, $f(-2) = 12 - k$（一次項 $-(-2)$ 寫成 $-2$ 而非 $+2$）→ 結果 $(10 - k) - (12 - k) = -2$（仍唔係 $-k$）。具體須再 trace 學生可能點計錯。

- 結論：**I 唔必為正確** ✗

**II. X 嘅 IQR = Y 嘅 IQR**
- 用 Tukey method：
  - $Q_1(X) = \dfrac{\alpha+\beta}{2}$、$Q_3(X) = \dfrac{\delta+\lambda}{2}$
  - $IQR(X) = \dfrac{\delta+\lambda}{2} - \dfrac{\alpha+\beta}{2} = \dfrac{\delta+\lambda-\alpha-\beta}{2}$
  - $Q_1(Y) = \dfrac{(\alpha-2)+(\beta-2)}{2} = \dfrac{\alpha+\beta}{2} - 2$
  - $Q_3(Y) = \dfrac{(\delta-2)+(\lambda-2)}{2} = \dfrac{\delta+\lambda}{2} - 2$
  - $IQR(Y) = \dfrac{\delta+\lambda}{2} - 2 - \left(\dfrac{\alpha+\beta}{2} - 2\right) = \dfrac{\delta+\lambda-\alpha-\beta}{2}$
- $IQR(X) = IQR(Y)$ 必為正確 ✓

**III. X 嘅 SD < Y 嘅 SD**
- $Y$ 數據 = $X$ 數據刪去 $\gamma$ 後各 −2
- 減常數唔影響 variance
- 從 5 數刪去中間一數 $\gamma$（喺 mean 附近）→ 留下嘅 4 數 variance 增大
- 一般情況：$\sigma(Y) > \sigma(X)$ 必為正確 ✓（除 $\gamma$ 為極端值嘅特殊情況，可能性低）

3. 結論：只有 II 及 III 啱 → **答案 C** ✓

【陷阱分析】
- A. 只有 I 及 II：III 錯（可能將 SD 比較搞混）
- B. 只有 I 及 III：II 錯（可能用 median-split quartile 方法算錯 IQR）
- C. 只有 II 及 III：✅ 對
- D. I, II, III：I 唔必為正確

【秒殺技巧】IQR 計算用 Tukey method：$Q_1 = \text{median of lower half}$、$Q_3 = \text{median of upper half}$；SD 比較記住「刪中間值會增加 spread」。
