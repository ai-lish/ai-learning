Ch11 與直線和三角形相關的角

相交線 · 平行線 · 三角形內角和

📐 11.1 與相交線有關的角
① 直線上的鄰角
在同一條直線上相鄰的角，擁有公共頂點和公共邊，合併成平角。
性質：相加 = 180°（平角）
a + b = 180°　（直線上的鄰角）
例子：一直線上有兩角，分別是 x 和 65°
→ x + 65° = 180°
→ x = 115°
📌 補角：兩個角相加 = 180°，稱為互為補角
② 同頂角
以同一個點為頂點的多個角，合併成周角。
性質：相加 = 360°（周角）
a + b + c = 360°　（同頂角）
例子：三個角分別是 x、90°、135°
→ x + 90° + 135° = 360°
→ x = 135°
③ 對頂角
兩直線相交，相對且不相鄰的一對角。
性質：對頂角相等
∠A = ∠B　（對頂角）
例子：兩線相交，一個角是 128°，另一個是 90°+x
→ 90° + x = 128°
→ x = 38°
💡 記憶：看到「X」形 → 對頂角相等
📏 11.2 與平行線有關的角
前提：AB // CD（平行線），截線 transversal 穿過兩線
① 同位角 — F 形
位置：平行線同一方 + 截線同側
性質：相等
簡記：同位角，AB // CD
例子：x + 26° = 64°　→　x = 38°
② 內錯角 — Z 形
位置：夾在平行線之間 + 截線兩側
性質：相等
簡記：內錯角，AB // CD
例子：y = 53°
③ 同旁內角 — C/U 形
位置：夾在平行線之間 + 截線同一側
性質：相加 = 180°
簡記：同旁內角，AB // CD
例子：x + 53° = 180°　→　x = 127°
🧠 記憶口訣：
• F 形 → 同位角 → 相等
• Z 形 → 內錯角 → 相等
• C/U 形 → 同旁內角 → 相加 = 180°
📐 11.3 三角形內角和
三角形分類
按邊長分：
  • 等邊三角形：三邊相等
  • 等腰三角形：兩邊相等
  • 不等邊三角形：三邊都不等
按內角分：
  • 銳角三角形：三角 < 90°
  • 直角三角形：一角 = 90°
  • 鈍角三角形：一角 > 90°
三角形內角和
A + B + C = 180°　（△ 內角和）
例子：三角形的角是 x、80°、58°
→ x + 80° + 58° = 180°
→ x = 42°
直線上的鄰角
如圖，AB 是一直線，∠AOC = 65°，求 x。
提示：直線上的鄰角相加 = 180°
對頂角
兩直線 AB、CD 相交於 O點。已知 ∠AOC = 128°，∠BOC = 90°+x，求 x。
提示：對頂角相等
同位角
如圖，AB // CD，截線 EF 產生同位角。已知 ∠x = x+26°，另一個 = 64°，求 x。
提示：同位角相等 → x + 26° = 64°
內錯角
如圖，AB // CD，截線 EF 產生內錯角。已知 ∠y = 53°，求另一個內錯角。
提示：內錯角相等
三角形內角和
△ABC 中，∠A = x，∠B = 80°，∠C = 58°。求 x。
提示：三角形內角和 = 180°
