📏 3.1 斜率（Slope）
斜率公式
若 $A(x_1, y_1)$ 和 $B(x_2, y_2)$，則： $$m = \frac{y_2 - y_1}{x_2 - x_1}$$
例子： A(-5, 2) 和 B(-2, 8)
$m = \frac{8-2}{-2-(-5)} = \frac{6}{3} = 2$
斜率的物理意義
• $m > 0$：由左至右向上傾斜
• $m < 0$：由左至右向下傾斜
• $m = 0$：水平線
• 垂直線：斜率不存在（無窮大）
垂直線的斜率關係
若兩直線垂直（非水平、非垂直），則： $$m_1 \times m_2 = -1$$
💡 跳遠問題：運動員從起跳線落地時，最短距離是垂直於起跳線的線段。
⚠️ 注意：當起跳線為水平線（$m_1=0$）或垂直線時，$m_1 \times m_2 = -1$ 不適用。
📐 3.2 直線方程的各种形式
點斜式（已知一點＋斜率）
$$\frac{y - y_1}{x - x_1} = m$$
例：通過 $(-5, 2)$，斜率 $m = 3$
$\frac{y-2}{x-(-5)} = 3$ → $y = 3x + 17$
兩點式（已知兩點）
$$\frac{y - y_1}{x - x_1} = \frac{y_2 - y_1}{x_2 - x_1}$$
例：通過 $A(1,3)$ 及 $B(3,7)$
$\frac{y-3}{x-1} = \frac{7-3}{3-1} = 2$ → $y = 2x + 1$
截距式（已知 x、y 截距）
$$\frac{x}{a} + \frac{y}{b} = 1$$
例：$x$ 截距 $= 2$，$y$ 截距 $= 6$
$\frac{x}{2} + \frac{y}{6} = 1$ → $3x + y - 6 = 0$ → $y = -3x + 6$
一般式（Standard Form）
$$Ax + By + C = 0 \quad (A > 0)$$
💡 統一公式策略
無論哪種題型，都可以這樣做：
1. 先求斜率 $m$
2. 用點斜式 $\frac{y-y_1}{x-x_1} = m$ 寫出方程
3. 化成一般式 $Ax + By + C = 0$（要求 $A > 0$）
📝 例題演練
例題 1：點 + 斜率
已知直線通過 $(-5, 2)$，斜率為 $3$，求直線方程。
▶ 顯示解答
代入點斜式：$\frac{y - 2}{x - (-5)} = 3$

$\frac{y - 2}{x + 5} = 3$
$y - 2 = 3(x + 5) = 3x + 15$
$\Rightarrow y = 3x + 17$

一般式：$3x - y + 17 = 0$

答案：$y = 3x + 17$ 或 $3x - y + 17 = 0$
例題 2：兩點式
求通過 $A(1, 3)$ 及 $B(3, 7)$ 的直線方程。
▶ 顯示解答
斜率 $m = \frac{7-3}{3-1} = \frac{4}{2} = 2$

代入點斜式（用 A 點）：$\frac{y - 3}{x - 1} = 2$
$y - 3 = 2x - 2$
$\Rightarrow y = 2x + 1$

一般式：$2x - y + 1 = 0$

答案：$y = 2x + 1$ 或 $2x - y + 1 = 0$
例題 3：截距式
已知 $x$ 截距為 $2$，$y$ 截距為 $6$，求直線方程。
▶ 顯示解答
代入截距式：$\frac{x}{2} + \frac{y}{6} = 1$

兩邊乘 6：$3x + y = 6$
移項：$3x + y - 6 = 0$

斜率 $m = -\frac{3}{1} = -3$
$\Rightarrow y = -3x + 6$

答案：$y = -3x + 6$ 或 $3x + y - 6 = 0$
例題 4：垂直線判斷
判斷以下兩直線是否垂直：
L₁：$y = 2x + 1$（即 $m_1 = 2$）
L₂：$x + 2y - 5 = 0$（即 $m_2 = -\frac{1}{2}$）
▶ 顯示解答
L₁：$m_1 = 2$
L₂：$2y = -x + 5$ → $y = -\frac{1}{2}x + \frac{5}{2}$，所以 $m_2 = -\frac{1}{2}$

計算：$m_1 \times m_2 = 2 \times (-\frac{1}{2}) = -1$

答案：兩直線垂直 ✓
