漢字讀音
問 1. 彼の 功績 は永く称えられるだろう。
  1. こうせき
  2. こうじゃく
  3. こうしゃく
  4. こうしょく
👀 睇答案
正解：1. こうせき — 「こうしゃく」「こうじゃく」係誤讀。
漢字讀音
問 2. 両国の 提携 関係は三十年に及ぶ。
  1. ていけい
  2. ていしょう
  3. ていせき
  4. ていりゃく
👀 睇答案
正解：1. ていけい — 「ていしょう」「ていせき」係誤讀。
語彙
問 3. 彼の説明はいつも 端的 で分かりやすい。
  1. たんてき
  2. たえてき
  3. たんに
  4. たんでき
👀 睇答案
正解：1. たんてき — 「簡潔」嘅意思。
語彙
問 4. その意見には 一理 あると思う。
  1. いちり
  2. ひとり
  3. いちすじ
  4. ひとふで
👀 睇答案
正解：1. いちり — 「少し道理がある」嘅意思。
文法形式
問 5. 彼女は何も言わなかった。——、 表情は怒りを示していた。
  1. それで
  2. それなのに
  3. それどころか
  4. それにしても
👀 睇答案
正解：3. それどころか — 「豈止如此，甚至」嘅意思。「何も言わなかった」已經 negative，「表情は怒り」係 even more negative 嘅轉折，所以用「それどころか」。
文法形式
問 6. 大雨が降った——、 試合は予定通り行われた。
  1. ので
  2. ために
  3. にもかかわらず
  4. ものの
👀 睇答案
正解：3. にもかかわらず — 「儘管下大雨，比賽仍如期進行」係逆接。
読解
問 7. 筆者が最も言いたいことは何か。（出典：論説文「AI と作文教育」）
  1. AI の文章生成技術を教育に導入すべきではない。
  2. AI を批判的に活用する教育方法を導入すべきだ。
  3. 作文教育は AI 以前の伝統的な方法に戻すべきだ。
  4. 大人だけが AI を使えば十分であり、子供は使うべきではない。
👀 睇答案
正解：2 — 筆者立場係「AI 完全禁止」同「完全接受」之間，主張 critical + guided use，呢個答案最 match 全文 tone。
