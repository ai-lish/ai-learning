1.1 實數系

整數、有理數和無理數組成實數系。

A 整數

正整數、負整數和零組成整數系。正整數亦稱為自然數；本頁把 0 與自然數分開。

…, −3, −2, −1, 0, 1, 2, 3, …

B 有理數

如果一個數可以寫成 p⁄q，其中 p、q 是整數而 q ≠ 0，這個數就是有理數。

有理數的小數表示可以是有盡小數或循環小數，例如 7⁄10 = 0.7、2⁄9 = 0.222…。

C 無理數

不能寫成 p⁄q 的數稱為無理數；它們是無盡且非循環小數。

π = 3.141592…，√5 = 2.236067…

D 實數

有理數和無理數合在一起，組成實數系。每個實數都可以在實數線上以一個點表示。

含平方根符號的數不一定是無理數，例如 √49 = 7 是有理數；但不能寫成分數的 √5 是無理數。

循環小數化成分數

設 x = 0.333…。

10x = 3.333…

10x − x = 3，9x = 3，x = 1⁄3

如果循環部分有兩個數字，例如 x = 0.1232323…，便同時乘以 100，再相減消去循環部分。

根式的最簡形式

√18 = √(32 × 2) = 3√2

√(3⁄16) = √3⁄4

分母有理化

撤去分母中的根式，稱為分母有理化。

√(4⁄7) = 2⁄√7 = 2√7⁄7

1.2 複數系

由虛數單位 i 延伸實數系，並學習複數運算。

A 虛數和複數

因為 x2 + 1 = 0 沒有實數解，所以引入虛數單位 i：

虛數單位i2 = −1
複數一般式a + bi
實部與虛部a 是實部，b 是虛部

當 b = 0 時，a + bi 就是實數；當 a = 0 而 b ≠ 0 時，就是純虛數。

B i 的乘方循環

i01
i1i
i2−1
i3−i

之後每四次重複一次，所以先把指數除以 4 看餘數。

C 複數的基本運算

(a + bi) + (c + di) = (a + c) + (b + d)i

(a + bi)(c + di) = (ac − bd) + (ad + bc)i

除法通常把分子、分母同乘以分母的共軛複數。

例子

(3 − 2i) + (−1 + i) = 2 − i

2i(3 + 4i) = 6i + 8i2 = −8 + 6i

(5 + 2i)(5 − 2i) = 25 − (2i)2 = 29

1.3 利用因式法解二次方程

把二次方程化成兩個因式的乘積，再利用零乘積性質。

基本步驟

把方程整理成一般式 ax2 + bx + c = 0。
把左方因式分解。
由 PQ = 0 得出 P = 0 或 Q = 0。
逐一解出根，並代回原方程檢查。

提取公因式

2x2 − 6x = 2x(x − 3)

平方差

x2 − 9 = (x − 3)(x + 3)

十字相乘法

x2 + x − 6 = (x + 3)(x − 2)

例：解 x2 + x − 6 = 0

(x + 3)(x − 2) = 0

x + 3 = 0 或 x − 2 = 0

所以 x = −3 或 x = 2。

首項係數為 1 的因式分解練習

輸入 x2 + bx + c 的 b 和 c，尋找兩個整數因式。

按「開始分解」查看因式和根。

1.4 利用二次公式解二次方程

對一般式二次方程，利用判別式及二次公式求根。

A 取平方根法

若方程可以整理成 (x + B)2 = C，而且 C ≥ 0，便可兩邊取平方根：x + B = ±√C。

(x − 3)2 = 16

x − 3 = ±4

所以 x = 7 或 x = −1。

若 C < 0，方程沒有實數解。

B 二次公式

對於 ax2 + bx + c = 0（a ≠ 0），根為：

x = (−b ± √(b2 − 4ac))⁄(2a)

判別式 D > 0有兩個不相等實根。
判別式 D = 0有兩個相等實根。
判別式 D < 0沒有實根；根為非實數。

例：解 2x2 − 3x − 5 = 0

a = 2，b = −3，c = −5

D = (−3)2 − 4(2)(−5) = 49

x = (3 ± √49)⁄4 = (3 ± 7)⁄4

所以 x = 5⁄2 或 x = −1。

二次公式計算器

輸入一般式的 a、b、c；計算器會顯示判別式及根的類型。

按「求根」查看結果。

1.5 利用圖解法解二次方程

把方程改寫為二次函數，x 軸截距就是方程的根。

圖像與根的關係

  • 先畫出 y = ax2 + bx + c 的圖像。
  • 圖像與 x 軸相交的位置，其 x 坐標就是二次方程的實根。
  • 圖像與 x 軸有兩個、相切或沒有交點，分別對應兩個不相等實根、兩個相等實根或沒有實根。
圖解法可以估算根的位置；若要得到精確根，應配合因式法或二次公式。

二次函數圖像

調整 a、b、c，觀察拋物線及 x 軸截距。

按「繪畫」查看圖像及根的數目。

1.6 涉及二次方程的應用題

把文字條件轉化為方程，解出後檢查答案是否符合情境。

解題五步

用字母（例如 x）代表未知數。
依題意建立二次方程。
選擇合適的方法解方程。
檢查答案是否合理，例如長度不可為負數。
用完整句子寫出問題所求的答案。

例：兩個連續正整數

兩個連續正整數的積比它們的和大 155。求這兩個數。

設較小的數為 x，另一個數為 x + 1。

x(x + 1) = x + (x + 1) + 155

x2 − x − 156 = 0 = (x − 13)(x + 12)

x = 13 或 x = −12

因為兩數是正整數，所以答案是 13 和 14。

常見情境

連續數、兩數關係、面積和長度。

建立方程

先畫圖或列出已知量，再把條件寫成等式。

最後檢查

捨去不合乎題意的根，並核對單位及正負。

連續正整數模型

輸入「積比和大多少」，即時建立並解出兩個連續正整數。

按「解題」查看模型。

1.7 利用已知根來建立二次方程

由解方程的逆運算，利用已知的根建立方程。

由兩個根建立方程

若二次方程的根是 α 和 β，則：

x = α 或 x = β

(x − α)(x − β) = 0

x2 − (α + β)x + αβ = 0

如果根含有分數，可把整條方程乘以適當的數，使各項係數成為整數。

例：根為 2 和 6

(x − 2)(x − 6) = 0

x2 − 8x + 12 = 0

已知根建方程

輸入兩個根（可輸入整數、小數或分數，例如 1/2），建立最簡整數係數方程。

按「建立方程」查看結果。
