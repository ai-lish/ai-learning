1.1

實數系

有理數可寫成 p/q（p, q ∈ ℤ 且 q ≠ 0）；不能寫成此形式的是無理數。有理數和無理數合稱實數。

  • 分數的小數表示是有限小數或循環小數。
  • 本頁自然數採 1, 2, 3, …；0 不列作自然數。
1.2

複數系

複數寫成 a + bi，其中 a, b ∈ ℝ；a 是實部、b 是虛部，並且 i² = −1。

  • 實部為 0 且虛部不為 0 的複數是純虛數。
  • 注意：虛部是 b，不是 bi。
1.3

利用因式法解二次方程

先把方程整理為 ax² + bx + c = 0，再因式分解，最後使用零乘積性質。

(x − α)(x − β) = 0 ⇒ x = α 或 x = β

容易混淆：有理數不等於整數；0 是整數、非負整數及非正整數，但不是正數、負數或本頁定義的自然數。
