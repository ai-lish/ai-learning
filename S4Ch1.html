本章學習路線

由實數與複數開始，逐步學習解一元二次方程的代數方法、圖解方法及應用。七個課題集中在同一頁，方便課堂快速查閱。

二次公式
x = (−b ± √(b²−4ac)) ÷ 2a
1.1

實數系

有理數可寫成 p/q（p, q ∈ ℤ 且 q ≠ 0）；不能寫成此形式的是無理數。有理數和無理數合稱實數。

  • 分數的小數表示是有限小數或循環小數。
  • 本頁自然數採 1, 2, 3, …；0 不列作自然數。
1.2

複數系

複數寫成 a + bi，其中 a, b ∈ ℝ；a 是實部、b 是虛部，並且 i² = −1。

  • 實部為 0 且虛部不為 0 的複數是純虛數。
  • 注意：虛部是 b，不是 bi。
1.3

利用因式法解二次方程

先把方程整理為 ax² + bx + c = 0，再因式分解，最後使用零乘積性質。

(x − α)(x − β) = 0 ⇒ x = α 或 x = β

1.4

利用二次公式解二次方程

對 ax² + bx + c = 0（a ≠ 0）直接代入公式，並先計算判別式 Δ = b² − 4ac。

  • Δ > 0：兩個不相等實根。
  • Δ = 0：一個重根。
  • Δ < 0：沒有實根。
1.5

利用圖解法解二次方程

把方程改寫為 y = ax² + bx + c，二次函數圖像與 x 軸的交點，其橫坐標就是方程的實根。

1.6

涉及二次方程的應用題

先定義未知數，按題意建立方程，解方程後檢查單位、範圍和題意，剔除不合理的根。

1.7

利用已知根來建立二次方程

若兩根為 α、β，可用 (x − α)(x − β) = 0 建立方程，再展開及整理。

容易混淆：有理數不等於整數；0 是整數、非負整數及非正整數，但不是正數、負數或本頁定義的自然數。
