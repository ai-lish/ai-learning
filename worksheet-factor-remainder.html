💡 核心概念

因式定理：如果 f(a) = 0，則 (x − a) 是 f(x) 的因式 餘式定理：f(x) 除以 (x − a) 的餘式 = f(a) 特別：f(x) 可被 (ax−b) 整除 ⟺ f(b/a) = 0

2021 P2 QQ08 ★ B
設 p(x) 為一多項式。當 p(x) 除以 x+1 時，餘數為 -2。若 p(x) 可被 x-1 整除，求當 p(x) 除以 x^2-1 時的餘式。
  • x+1
  • x-1
  • -x+1
  • -x-1
提示：
1. 「可被整除」= 因式定理 → f(b/a) = 0
2. 「除以 (x−a) 的餘式」= 餘式定理 → 直接代 x = a
3. 除以 (ax−b) 的餘式：先求 f(b/a)
4. 除以 x²−1 = (x−1)(x+1)：需同時滿足兩個條件
