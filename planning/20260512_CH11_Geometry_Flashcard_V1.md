# 20260512_CH11_Geometry_Flashcard_V1

## 項目概述

**目標：** 中一「第11章 與直線和三角形相關的角」互動公式翻轉卡

**兩種模式：**
- 簡報模式：上而下展示全部7張卡（如 Google Slides）
- 隨機模式：隨機順序，點擊切換下一張（不重複）

---

## 每張卡結構

```
正面（公式）←→ 背面（例題）
```

**正面（公式）：**
- Canvas 圖像 + 可拖放變量（x, y, z, 180°, 360°）
- 直線上的鄰角：可選 2/3/4 個鄰角
- 同頂角：可選 3/4/5 個角
- 拖放驗證

**背面（例題）：**
- Canvas 圖像（特定角度）
- 拖放驗證
- 驗證後顯示「正確公式 + 理由」
- □ □ □ 步驟方格（剔選 → 順序揭小步驟+答案）

**流程：**
1. 封面重溫公式 → 反轉
2. 例題拖放驗證 → 顯示正確公式+理由
3. 剔選步驟方格 → 順序揭小步驟+答案
4. 反轉回同卡封面

---

## 7個定理

| ID | 名稱 | 公式 | 理由 |
|----|------|------|------|
| 1 | 直線上的鄰角 | x + y = 180°（可選2-4個） | （直線上的鄰角） |
| 2 | 同頂角 | x + y + z = 360°（可選3-5個） | （同頂角） |
| 3 | 對頂角 | x = y | （對頂角） |
| 4 | 同位角 | x = y | （同位角, AB//CD） |
| 5 | 錯角 | x = y | （錯角, AB//CD） |
| 6 | 同旁內角 | x + y = 180° | （同旁內角, AB//CD） |
| 7 | 三角形內角和 | x + y + z = 180° | （三角形內角和） |
