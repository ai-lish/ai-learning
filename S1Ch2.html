2.1 · CORE IDEA

有向數由兩部分組成

有向數（directed number）包含「正負號」和「數值」。正號表示在 0 的右方，負號表示在 0 的左方。

\(+a\)　或　\(-a\) 此處 \(a>0\)；符號指出方向，\(a\) 表示距離 \(0\) 的數值。
  • 正數大於 \(0\)；負數小於 \(0\)。
  • \(0\) 既不是正數，也不是負數。
  • 正數的正號通常可以省略：\((+8)=8\)；負號不能省略。
教材對照：2.1，教材 2.3–2.6 頁
2.1 · OPPOSITES

相反數及數值

兩個有向數的數值相同、正負號相反，就互為相反數。

\(a\) 的相反數是 \(-a\)，而 \(a+(-a)=0\)。

例如：\(+7\) 的相反數是 \(-7\)；\(-\frac12\) 的相反數是 \(+\frac12\)。\(0\) 的相反數仍然是 \(0\)。

本課用語：本頁沿用教材的「數值」說法，表示有向數距離 \(0\) 的大小；圖例每格代表 1，遇到 \(-\frac12\) 時應讀作「在 0 左邊半個單位」。
練習回饋連接：先說清楚「在 0 的左方／右方幾格」，再說正負號。
教材對照：2.1，教材 2.3–2.6 頁
2.1 · COMPARE

比較有向數的大小

在數線上，右方的數一定較大，左方的數一定較小。

  • 任何正數都大於任何負數：\(3>-5\)。
  • 兩個正數比較數值：\(8>5\)。
  • 兩個負數比較時，較接近 \(0\) 的數較大：\(-2>-7\)。
\(-7<-2<0<5\)
練習回饋：「−1 在數線上位於 −4 的右方，所以 −1 ＞ −4。」
教材對照：2.1，教材 2.7–2.16 頁
2.2–2.4 · OPERATING HABIT

每次運算先問兩句

  1. 這個符號是「正負號」，還是「運算符號」？
  2. 應該先處理括號、乘除，還是加減？
先看符號　→　再看次序　→　最後計算

寫清楚中間步驟，尤其是減去負數和負數相乘。

練習回饋句式：位置 → 方向 → 數值 → 答案。
教材對照：2.2–2.4，教材 2.17–2.49 頁
2.2 · ADD / SUBTRACT

加法及減法

把運算想成數線上的移動：先看第二個數的方向。

加上正數：向右移
加上負數：向左移
減去正數：向左移
減去負數：向右移
練習回饋：「加上 +3 即向右移 3 格。」
教材對照：2.2，教材 2.17–2.34 頁
2.3 · MULTIPLY / DIVIDE

乘法及除法

乘除題先用數線確認結果在 0 的哪一邊，再計算不帶符號的數值距離；乘法和除法的符號規則相同。

非零數同號 → 正
非零數異號 → 負
多個因數：負號偶數 → 正
多個因數：負號奇數 → 負
任何數 \(\times 0=0\)
\(0\div\) 非零數 \(=0\)
除數不可為 \(0\)
練習回饋：先判斷符號方向，再計算數值距離；同號相除得正，異號相乘得負。
教材對照：2.3，教材 2.35–2.42 頁
2.4 · ORDER

四則混合運算次序

每一步只處理同一層次，並把中間式寫清楚。

括號 → 乘除 → 加減
同級運算：由左至右
練習回饋：先算 \((-6)\times(-5)=+30\)，再算 \(-7-30=-37\)。
教材對照：2.4，教材 2.43–2.49 頁
2.2 · REMOVE BRACKETS

先處理括號內的符號

減去一個數，就是加上它的相反數；所以減去負數會向右移。

\(a+(+b)=a+b\)
\(a+(-b)=a-b\)
\(a-(+b)=a-b\)
\(a-(-b)=a+b\)
練習回饋：減去負數變成加上正數。
教材對照：2.2，教材 2.23–2.34 頁

數線：把符號變成位置

按一個數字，數線會標出該點及它距離 0 的單位數。

水平數線

由左至右，數字由小至大；\(0\) 是原點，右方是正方向，左方是負方向。

請選擇一個數字。
READ THE LINE

從位置讀大小

例如 \(-2\) 在 \(-1\) 的左邊，所以 \(-2<-1\)。雖然 \(2\) 的數值小於 \(-7\) 的數值（\(2<7\)），但 \(2\) 在右方，因此 \(2>-7\)。

右方 \(>\) 左方
MOVE ON THE LINE

用移動理解加減

加上正數向右移；加上負數向左移。減去正數向左移；減去負數向右移。

\(a+(-b)=a-b\)
\(a-(-b)=a+b\)

例題：每步只做一件事

先自行想，再按「顯示步驟」核對。

例題 1 · 比較大小

比較 \(-3\) 和 \(-2\)

\(-3\quad ? \quad -2\)

\(-3\) 在數線上位於 \(-2\) 的左方。

所以 \(-3<-2\)。

教材例題：2.1，教材 2.10 頁
例題 2 · 減去負數

計算 \((-14)-(-19)\)

\((-14)-(-19)\)

減去負數變成加上正數：

\((-14)-(-19)=-14+19\)

\(=5\)

教材例題：2.2，教材 2.27 頁
例題 3 · 乘除符號

計算 \((-5)\times(-4)\) 及 \((-35)\div(+7)\)

\((-5)\times(-4)\qquad (-35)\div(+7)\)

同號相乘得正：\((-5)\times(-4)=20\)。

異號相除得負：\((-35)\div(+7)=-5\)。

答案：\(20\)，\(-5\)

教材例題：2.3，教材 2.37、2.40 頁
例題 4 · 混合運算

計算 \((-7)-(-6)\times(-5)\)

\((-7)-(-6)\times(-5)\)

先做乘法：\((-6)\times(-5)=+30\)。

再做減法：\((-7)-(+30)=-7-30\)。

\(=-37\)

教材例題：2.4，教材 2.43 頁
易錯位：混合運算不能由右至左亂算；乘除要先做，而且同級的乘除要由左至右。
