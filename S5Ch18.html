📝 概率的古典定義
\(P(A) = \frac{n(A)}{n(S)}\)

n(A) = 有利結果數量  |  n(S) = 總結果數量

18.2 概率的加法定律

⚡ 互斥事件

P(A ∪ B) = P(A) + P(B)
兩事件不能同時發生

🔄 互補事件

P(A') = 1 - P(A)
A 與 A' 必有一件發生
兩個事件能否同時發生？ → 不能 → 互斥 / 互補
📖 例題：互斥 vs 非互斥

擲骰子：

事件 A = 擲到 1 或 2 = {1, 2}

事件 B = 擲到 2 或 3 = {2, 3}

→ A 和 B 有共同元素 2，不是互斥

事件 C = 擲到 1 或 2 = {1, 2}

事件 D = 擲到 4 或 6 = {4, 6}

→ C 和 D 沒有共同元素，是互斥

一般加法定律（任何兩事件）：

\(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)

互斥事件加法定律：

\(P(A \cup B) = P(A) + P(B)\)

互補事件：

\(P(A') = 1 - P(A)\)
例：P(不是1) = ?

P(不是1) = 1 - P(1) = 1 - 1/6 = 5/6

18.3 概率的乘法定律

🎲 獨立事件

P(A ∩ B) = P(A) × P(B)
一個事件不影響另一個

📊 條件概率

P(A|B) = P(A ∩ B) / P(B)
已知 B 發生，A 的概率
一個事件影響另一個？ → 不影響 → 獨立 / 影響 → 相關
🎲 例題：擲兩次硬幣（獨立）
1
P(第一次正面) = 1/2
2
P(第二次正面) = 1/2（第一次結果不影響第二次）
3
P(兩次都正面) = P(第一次正面) × P(第二次正面) = 1/2 × 1/2 = 1/4

獨立事件乘法定律：

\(P(A \cap B) = P(A) \times P(B)\)

條件概率公式：

\(P(A|B) = \frac{P(A \cap B)}{P(B)}\)

相關事件乘法定律：

\(P(A \cap B) = P(A) \times P(B|A)\)
例：條件概率

已知擲到偶數，求擲到 2 的概率

P(2|偶數) = P({2}) / P({2,4,6}) = (1/6) / (3/6) = 1/3

18.4 概率與排列組合

🔢 排列概率 P

\(P^n_r = \frac{n!}{(n-r)!}\)
考慮次序

📦 組合概率 C

\(C^n_r = \frac{n!}{r!(n-r)!}\)
唔考慮次序
次序重要嗎？ → 重要 → P / 不重要 → C
📦 例題：啤牌概率

一副啤牌 52 張，求全部都是紅桃的概率：

1
總可能性：C(52,3) = 22,100 種
2
有利情況：C(13,3) = 286 種（13張紅桃中選3張）
3
P = 286 / 22,100 ≈ 0.0129

解概率應用題四步曲：

  1. 確定課題 — 是 P（排列）還是 C（組合）？
  2. 計算總可能性 — n(S)
  3. 計算有利情況 — n(A)
  4. 求概率 — P(A) = n(A) / n(S)

📌 公式速記

古典概率

\(P(A) = \frac{n(A)}{n(S)}\)

加法（互斥）

\(P(A \cup B) = P(A) + P(B)\)

乘法（獨立）

\(P(A \cap B) = P(A) \times P(B)\)

條件概率

\(P(A|B) = \frac{P(A \cap B)}{P(B)}\)

互補

\(P(A') = 1 - P(A)\)

✏️ 18.1 集合的語言 - 互動測驗

基礎
一副啤牌有 52 張，隨機抽一張。設 A = 抽到紅桃，B = 抽到 Ace。求 n(A) 和 n(A ∩ B)。
✅ 正確！ 紅桃有 13 張，紅桃 Ace 只有 1 張。
基礎
擲一粒骰子。設 A = 擲到偶數，B = 擲到大過3。求 A ∩ B 的元素。
✅ 正確！ 偶數 = {2,4,6}，大過3 = {4,5,6}，交集 = {4,6}
進階
P(A ∪ B) = ? （A、B 為互斥事件）
✅ 正確！ 互斥事件：A 和 B 不會同時發生，所以 P(A ∪ B) = P(A) + P(B)

✏️ 18.2 概率的加法定律

基礎
設 P(A) = 0.4，求 P(A')。
✅ 正確！ P(A') = 1 - P(A) = 1 - 0.4 = 0.6
基礎
擲骰子，設 A = 擲到1或2，B = 擲到3或6。求 P(A ∪ B)。
✅ 正確！ A = {1,2}，B = {3,6}，互斥（沒有共同元素）
P(A ∪ B) = P(A) + P(B) = 2/6 + 2/6 = 4/6 = 2/3

✏️ 18.3 概率的乘法定律

基礎
連續擲兩次硬幣，兩次都擲到正面的概率是多少？
✅ 正確！ 獨立事件：P(正正) = P(第一次正面) × P(第二次正面) = 1/2 × 1/2 = 1/4
進階
袋有3個紅球和2個藍球，無放回抽取2次。第一次抽到紅球且第二次抽到藍球的概率？
✅ 正確！ 相關事件（無放回）：
P(紅然後藍) = P(第一次紅) × P(第二次藍|第一次紅) = 3/5 × 2/4 = 6/20 = 3/10

✏️ 18.4 概率與排列組合

基礎
一副啤牌 52 張，隨機抽 3 張。全部都是紅桃的概率？
✅ 正確！ 組合概率：P = C(13,3) / C(52,3) = 286 / 22100 ≈ 0.0129
注意：係 C（組合，唔考慮次序），唔係 P（排列）

📋 課本熱身練習 18.1

💡 提示：這些練習來自課本第 5 頁，可先溫習上面的集合概念再做。

基礎
從「GLASS」一詞中隨機選出一個字母。求選出字母「S」的概率。
📖 解答

GLASS 有 5 個字母：G, L, A, S, S

樣本空間 S = {G, L, A, S, S}，n(S) = 5

有利結果：「S」出現 2 次

P(S) = 2/5

基礎
從一副 52 張的啤牌中隨機選出一張牌。求選出「9」的概率。
📖 解答

52 張啤牌，每種點數有 4 張

n(S) = 52，「9」有 4 張

P(9) = 4/52 = 1/13

基礎
衣櫃有 4 條白裙、5 條藍裙、3 條綠裙。隨機選出一條。求 (a) 白裙 (b) 黃裙 (c) 白、藍或綠的概率。
📖 解答

n(S) = 4 + 5 + 3 = 12

(a) P(白) = 4/12 = 1/3

(b) P(黃) = 0/12 = 0（冇黃裙）

(c) P(白∪藍∪綠) = (4+5+3)/12 = 12/12 = 1（必然事件）

進階
從 7 名學生和 6 名老師中選 5 人組隊。(a) 冇限制 (b) 2 名學生和 3 名老師。各有多少種方法？
📖 解答

(a) C(13,5) = 1287 種

(b) C(7,2) × C(6,3) = 21 × 20 = 420 種

💡 解題關鍵：先用 C 揀人，再組合（乘）
