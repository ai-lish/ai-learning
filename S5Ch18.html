📦 樣本空間 S

所有可能結果的集合
S = {1, 2, 3, 4, 5, 6}

🎯 事件 A

樣本空間的子集
A = {2, 4, 6}
概率的基本概念 → 樣本空間 S + 事件 A

集合基本符號：

  • \(n(S)\) = 樣本空間 S 的元素數目
  • \(A \cup B\) = A 或 B（聯集）
  • \(A \cap B\) = A 和 B（交集）
  • \(A'\) = 不是 A（補集）
  • \(\emptyset\) = 空集（不可能事件）
  • \(U\) = 全集（必然事件）

例：擲骰子

設 A = 擲到偶數 = {2, 4, 6}，n(A) = 3

A' = {1, 3, 5}，n(A') = 3

📝 概率的古典定義
\(P(A) = \frac{n(A)}{n(S)}\)

n(A) = 有利結果數量  |  n(S) = 總結果數量

⚠️ 重要性質
  • 對於任何事件 A：\(0 \leq P(A) \leq 1\)
  • 不可能事件（如擲到 7）：\(P(A) = 0\)
  • 必然事件（如擲到 ≤6）：\(P(A) = 1\)
🎲 例題：擲硬幣兩次

投擲一枚均勻硬幣兩次，設 H=正面、T=反面。

樣本空間 S = {HH, HT, TH, TT}，n(S) = 4

事件 A = 擲得 2 個正面 = {HH}

事件 B = 恰好擲得 1 個反面 = {HT, TH}

P(A) = n(A)/n(S) = 1/4    P(B) = n(B)/n(S) = 2/4 = 1/2

18.2 概率的加法定律

⚡ 互斥事件

P(A ∪ B) = P(A) + P(B)
兩事件不能同時發生

🔄 互補事件

P(A') = 1 - P(A)
A 與 A' 必有一件發生
📖 例題：互斥 vs 非互斥

投擲骰子：

事件 A = 擲到 1 或 2 = {1, 2}

事件 B = 擲到 2 或 3 = {2, 3}

→ A 和 B 有共同元素 2，不是互斥

P(A ∪ B) = P(A) + P(B) - P(A ∩ B) = 2/6 + 2/6 - 1/6 = 3/6 = 1/2

投擲骰子：

事件 A = 擲到 1 或 2 = {1, 2}

事件 B = 擲到 4 或 6 = {4, 6}

→ A 和 B 沒有共同元素，是互斥

P(A ∪ B) = P(A) + P(B) = 2/6 + 2/6 = 4/6 = 2/3

📖 例題：互補事件

投擲一枚骰子，設 A = 擲到奇數 = {1, 3, 5}，A' = 擲到偶數 = {2, 4, 6}

P(A) = 3/6 = 1/2

P(A') = 1 - P(A) = 1 - 1/2 = 1/2

注意：A 和 A' 互為補集，必有一件發生

📖 例題：選學生（來自課本 p.16）

從一組學生中隨機選出一人。

事件 A：選出一名男學生

事件 B：選出一名女學生

→ 事件 A 和事件 B 不可能同時發生（互斥）

P(A ∪ B) = P(A) + P(B)

兩個事件能否同時發生？ → 不能 → 互斥 / 互補
📖 例題：互斥 vs 非互斥

擲骰子：

事件 A = 擲到 1 或 2 = {1, 2}

事件 B = 擲到 2 或 3 = {2, 3}

→ A 和 B 有共同元素 2，不是互斥

事件 C = 擲到 1 或 2 = {1, 2}

事件 D = 擲到 4 或 6 = {4, 6}

→ C 和 D 沒有共同元素，是互斥

一般加法定律（任何兩事件）：

\(P(A \cup B) = P(A) + P(B) - P(A \cap B)\)

互斥事件加法定律：

\(P(A \cup B) = P(A) + P(B)\)

互補事件：

\(P(A') = 1 - P(A)\)
例：P(不是1) = ?

P(不是1) = 1 - P(1) = 1 - 1/6 = 5/6

🔄 C. 互補事件

💡 定義：若事件 A 與事件 A' 滿足 A ∩ A' = ∅ 且 A ∪ A' = S，則 A' 為 A 的互補事件。
公式：P(A') = 1 - P(A)

🔄 互補事件性質

P(A') = 1 - P(A)
A 與 A' 必有一件發生

⚡ 互斥 ≠ 互補

互斥：A∩B = ∅
互補：還要 A∪B = S
判斷
投擲一枚骰子。事件 A = 擲得點數為奇數，事件 B = 擲得點數為偶數。
A 和 B 是否互為互補事件？
📖 解答

是互補事件。

A = {1, 3, 5}，B = {2, 4, 6} = A'

A ∩ B = ∅（不會同時發生）

A ∪ B = S（必有一件發生）

計算
袋有 4 張紙卡寫上 1、3、5、7。隨機抽一張。設事件 A = 抽到奇數。求 P(A')。
📖 解答

A = {1, 3, 5, 7}，n(A) = 4

A' = {}（冇其他選擇）

n(A') = 0，P(A') = 0/4 = 0

驗證：P(A) + P(A') = 4/4 + 0/4 = 1 ✓

程度一
從盒中隨機抽出一個球。哪一組是互補事件？

A: 抽到紅球 / 抽到白球
B: 抽到金球 / 抽到銀球
C: 抽到藍球 / 抽到不是藍球
✅ 只有 C 是互補事件：
A 錯：紅球和白球可能不是全部球
B 錯：金球和銀球可能不是全部球
C 對：「抽到藍球」和「抽到不是藍球」必然互補
18.3 概率的乘法定律

🎲 獨立事件

P(A ∩ B) = P(A) × P(B)
一個事件不影響另一個

📊 條件概率

P(A|B) = P(A ∩ B) / P(B)
已知 B 發生，A 的概率
一個事件影響另一個？ → 不影響 → 獨立 / 影響 → 相關
🎲 例題：擲兩次硬幣（獨立）
1
P(第一次正面) = 1/2
2
P(第二次正面) = 1/2（第一次結果不影響第二次）
3
P(兩次都正面) = P(第一次正面) × P(第二次正面) = 1/2 × 1/2 = 1/4

獨立事件乘法定律：

\(P(A \cap B) = P(A) \times P(B)\)

條件概率公式：

\(P(A|B) = \frac{P(A \cap B)}{P(B)}\)

相關事件乘法定律：

\(P(A \cap B) = P(A) \times P(B|A)\)
例：條件概率

已知擲到偶數，求擲到 2 的概率

P(2|偶數) = P({2}) / P({2,4,6}) = (1/6) / (3/6) = 1/3

📝 練習 18.3：獨立事件與條件概率（來自課本 P33-44）

程度一
皓明射球得分的概率是 0.3。他射球三次，求「三球都得分」的概率。
📖 解答

各次射球為獨立事件：

P(三次都得分) = 0.3 × 0.3 × 0.3 = 0.027

程度二
皓明射球得分的概率是 0.3。他射球三次，求「至多兩球得分」的概率。
📖 解答

P(至多兩球得分) = 1 - P(三球都得分)

= 1 - 0.3³

= 1 - 0.027 = 0.973

程度三
思哺乳答對的概率是 1/3，柏豪答對的概率是 1/4。求「至少一人答對」的概率。
📖 解答

P(至少一人答對) = 1 - P(兩人都答錯)

= 1 - (1 - 1/3) × (1 - 1/4)

= 1 - (2/3 × 3/4)

= 1 - 6/12 = 1/2

條件概率
袋子有 1 個紅球、1 個黃球和 1 個綠球。先後抽兩球，不放回。已知第一次是黃球，求第二次是紅球的概率。
📖 解答

第一次抽出黃球後，袋中剩 1 個紅球和 1 個綠球

P(第二次是 R | 第一次是 Y) = 1/2 = 0.5

判斷
判斷以下是否獨立事件：
(a) 投擲兩枚硬幣
(b) 從一副啤牌先後抽兩張，不放回
📖 解答

(a) 是獨立事件 — 第一枚結果不影響第二枚

(b) 不是獨立事件 — 第一次抽出後不放回，影響第二次的概率

18.4 概率與排列組合

🔢 排列概率 P

\(P^n_r = \frac{n!}{(n-r)!}\)
考慮次序

📦 組合概率 C

\(C^n_r = \frac{n!}{r!(n-r)!}\)
唔考慮次序
次序重要嗎？ → 重要 → P / 不重要 → C
📦 例題：啤牌概率

一副啤牌 52 張，求全部都是紅桃的概率：

1
總可能性：C(52,3) = 22,100 種
2
有利情況：C(13,3) = 286 種（13張紅桃中選3張）
3
P = 286 / 22,100 ≈ 0.0129

解概率應用題四步曲：

  1. 確定課題 — 是 P（排列）還是 C（組合）？
  2. 計算總可能性 — n(S)
  3. 計算有利情況 — n(A)
  4. 求概率 — P(A) = n(A) / n(S)

📝 練習 18.4：排列組合概率（來自課本 P58-74）

程度一
從 11 個球中選 5 個，其中 2 個是籃球、3 個是足球。求總選法數目。
📖 解答

使用乘法法則：

C(2,2) × C(4,3) = 1 × 4 = 4 種選法

解釋：從 2 個籃球中選 2 個 = C(2,2) = 1
從 4 個足球中選 3 個 = C(4,3) = 4
總選法 = 1 × 4 = 4

程度二
從 7 個籃球和 4 個足球中選 5 個。求「至少選 1 個足球」的概率。
📖 解答

P(至少 1 個足球) = 1 - P(沒有足球)

= 1 - C(7,5) / C(11,5)

= 1 - 21 / 462

= 1 - 7/154

= 147/154 ≈ 0.9545

程度三
廚房有 5 個紅色杯子、4 個藍色杯子和 3 個黃色碟子。選 3 個不同顏色的物品，求選法數目。
📖 解答

必須從三種顏色各選 1 件：

C(5,1) × C(4,1) × C(3,1) = 5 × 4 × 3 = 60 種

程度一
袋子 P 有 2 個綠球和 3 個白球；袋子 Q 有 3 個綠球和 7 個白球。從每個袋子各抽 1 個球。求「恰好有 1 個綠球」的概率。
📖 解答

P(1 綠) = P(P綠, Q白) + P(P白, Q綠)

= (2/5 × 7/10) + (3/5 × 3/10)

= 14/50 + 9/50

= 23/50 = 0.46

程度二
盒有 8 張歌星 A 的海報和 2 張歌星 B 的海報。先後抽 2 張，抽後放回。求「1 張 A、1 張 B」的概率。
📖 解答

P(1A,1B) = P(A,B) + P(B,A)

= (8/10 × 2/10) + (2/10 × 8/10)

= 16/100 + 16/100

= 32/100 = 0.32

✏️ 18.1 集合的語言 - 互動測驗

基礎
一副啤牌有 52 張，隨機抽一張。設 A = 抽到紅桃，B = 抽到 Ace。求 n(A) 和 n(A ∩ B)。
✅ 正確！ 紅桃有 13 張，紅桃 Ace 只有 1 張。
基礎
擲一粒骰子。設 A = 擲到偶數，B = 擲到大過3。求 A ∩ B 的元素。
✅ 正確！ 偶數 = {2,4,6}，大過3 = {4,5,6}，交集 = {4,6}
進階
P(A ∪ B) = ? （A、B 為互斥事件）
✅ 正確！ 互斥事件：A 和 B 不會同時發生，所以 P(A ∪ B) = P(A) + P(B)
基礎
設 A = {1,3,5} 和 B = {8}。求 (a) A ∩ B 和 (b) A ∪ B。
✅ 正確！ A∩B = ∅（沒有共同元素）；A∪B = {1,3,5,8}（所有元素）
進階
設 A = {1,2,4}、B = {2,3,4,5}。求 (a) A ∩ B 和 (b) A ∪ B。
✅ 正確！ A∩B = {2,4}（共同元素）；A∪B = {1,2,3,4,5}（所有不重複元素）

✏️ 18.2 概率的定義 P(A) = n(A)/n(S)

基礎
投擲硬幣兩次。事件 A = 擲得 2 個正面。P(A) = ?
✅ 正確！ S = {HH, HT, TH, TT}，n(S) = 4；A = {HH}，n(A) = 1；P(A) = 1/4
基礎
投擲骰子，事件 A = 擲到奇數，B = 擲到偶數。判斷：事件 A 和 B 是互斥事件嗎？
✅ 正確！ 奇數 = {1,3,5}，偶數 = {2,4,6}，沒有共同元素，是互斥。
進階
投擲骰子，事件 A = 擲到 {1,2}，B = 擲到 {4,6}。求 P(A ∪ B)。
✅ 正確！ A 和 B 互斥（沒有共同元素）
P(A ∪ B) = P(A) + P(B) = 2/6 + 2/6 = 4/6 = 2/3
進階
投擲骰子，事件 A = 擲到 {1,3,5}（奇數）。求 P(A')。
✅ 正確！ A' = 偶數 = {2,4,6}，P(A') = 1 - P(A) = 1 - 3/6 = 3/6 = 1/2
基礎
關於概率值 P(A)，以下哪個陳述是正確的？
✅ 正確！ 概率值永遠在 0 和 1 之間。不可能事件 P=0，必然事件 P=1。
進階
袋有 8 張紙卡，分別寫上 1-8。隨機抽一張。設事件 A = 抽出數字大過 4。求 P(A)。
✅ 正確！ A = {5,6,7,8}，n(A) = 4；n(S) = 8；P(A) = 4/8 = 1/2

✏️ 18.2 概率的加法定律

基礎
設 P(A) = 0.4，求 P(A')。
✅ 正確！ P(A') = 1 - P(A) = 1 - 0.4 = 0.6
基礎
擲骰子，設 A = 擲到1或2，B = 擲到3或6。求 P(A ∪ B)。
✅ 正確！ A = {1,2}，B = {3,6}，互斥（沒有共同元素）
P(A ∪ B) = P(A) + P(B) = 2/6 + 2/6 = 4/6 = 2/3

✏️ 18.3 概率的乘法定律

基礎
連續擲兩次硬幣，兩次都擲到正面的概率是多少？
✅ 正確！ 獨立事件：P(正正) = P(第一次正面) × P(第二次正面) = 1/2 × 1/2 = 1/4
進階
袋有3個紅球和2個藍球，無放回抽取2次。第一次抽到紅球且第二次抽到藍球的概率？
✅ 正確！ 相關事件（無放回）：
P(紅然後藍) = P(第一次紅) × P(第二次藍|第一次紅) = 3/5 × 2/4 = 6/20 = 3/10

✏️ 18.4 概率與排列組合

基礎
一副啤牌 52 張，隨機抽 3 張。全部都是紅桃的概率？
✅ 正確！ 組合概率：P = C(13,3) / C(52,3) = 286 / 22100 ≈ 0.0129

基礎
從「GLASS」一詞中隨機選出一個字母。求選出字母「S」的概率。
📖 解答

GLASS 有 5 個字母：G, L, A, S, S

有利結果：「S」出現 2 次

基礎
從一副 52 張的啤牌中隨機選出一張牌。求選出「9」的概率。
📖 解答

52 張啤牌，每種點數有 4 張

n(S) = 52，「9」有 4 張

P(9) = 4/52 = 1/13

基礎
衣櫃有 4 條白裙、5 條藍裙、3 條綠裙。隨機選出一條。求 (a) 白裙 (b) 黃裙 (c) 白、藍或綠的概率。
📖 解答

n(S) = 4 + 5 + 3 = 12

(a) P(白) = 4/12 = 1/3

(b) P(黃) = 0/12 = 0（冇黃裙）

(c) P(白∪藍∪綠) = (4+5+3)/12 = 12/12 = 1（必然事件）
