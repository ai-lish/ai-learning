§ 11.1

📏 直線上的鄰角

📐 定義

在同一直線上相鄰的角，擁有公共頂點和公共邊，合併成平角（180°）。

🔑 性質

兩角相加 = 180°。
稱為「互為補角」。

a + b = 180°
📝 例題
如圖，AB 是一直線，∠AOC = 65°，求 x。
x + 65° = 180°　→　x = 115°
§ 11.1

✝️ 對頂角

📐 定義

兩直線相交，相對且不相鄰的一對角。

🔑 性質

對頂角永遠相等。

∠A = ∠B
📝 例題
如圖，兩直線 AB、CD 相交於 O 點。已知 ∠AOC = 128°，∠BOC = 90°+x，求 x。
90° + x = 128°　→　x = 38°
§ 11.2

📐 同位角 — F 形

📐 位置

平行線同一方 + 截線同側

🔑 性質

相等

a = b
📝 例題
如圖，AB // CD，截線 EF 產生同位角。已知其中一個角係 64°，另一個係 x + 26°，求 x。
x + 26° = 64°　→　x = 38°
§ 11.2

⚡ 內錯角 — Z 形

📐 位置

夾在平行線之間 + 截線兩側

🔑 性質

相等

a = b
📝 例題
如圖，AB // CD，截線 EF 產生內錯角。兩個標示角度都係 53°。
內錯角相等 ✓
§ 11.2

🔗 同旁內角 — C/U 形

📐 位置

夾在平行線之間 + 截線同一側

🔑 性質

相加 = 180°（互為同旁內角）

a + b = 180°
📝 例題
如圖，AB // CD，截線 EF 產生同旁內角。已知其中一個角係 53°，另一個係 x°，求 x。
x + 53° = 180°　→　x = 127°
§ 11.3

📐 三角形內角和

任何三角形的內角總和

α + β + γ = 180°

適用於：銳角三角形、直角三角形、鈍角三角形、等邊三角形、等腰三角形

📐 三角形分類（按邊長）

• 等邊三角形：三邊相等
• 等腰三角形：兩邊相等
• 不等邊三角形：三邊都不等

📐 三角形分類（按內角）

• 銳角三角形：三角 < 90°
• 直角三角形：一角 = 90°
• 鈍角三角形：一角 > 90°

📝 例題
△ABC 中，∠A = x°，∠B = 80°，∠C = 58°。求 x。
x + 80° + 58° = 180°　→　x = 42°
形狀名稱關係備註
— 直線上的鄰角 a + b = 180° 互為補角

F 同位角 相等 AB // CD
Z 內錯角 相等 夾在中間，截線兩側
C/U 同旁內角 a + b = 180° 截線同側
