🧭 四捨五入步驟

估算三步曲 ── 截數 → 2選1 → 睇尾數
📖 估算三步曲

🧭 四捨五入的標準流程

四捨五入不是靠感覺，而係有明確的三步程序。每一步都有特定操作，記熟之後就唔會錯。

1
截數
將數字截斷至目標位值的下一位
→
2
2選1
選擇截斷結果或截斷結果 +1
→
3
睇尾數
尾數 ≥5 → 入；尾數 <5 → 捨
📝 完整例子

📌 例：$2.3 的士費四捨五入到元位

步驟演示（$2.3 → 取至元位）
目標：元位
→
睇仙位：3
→
仙位 3 ≥ 5 → 入
→
$3
答案：$3（仙位 3 ≥ 5，所以向上入）
例：2568 取至十位
① 截 → 2560
→
② 可揀 2560 或 2570
→
③ 8 ≥ 5 → 入
→
✅ 2570
個位 8 ≥ 5，所以入 → 2570
⚡ 四 vs 五 判斷

🎯 0-4 vs 5-9

👇
四捨（0–4）
尾數係 0、1、2、3、4
→ 唔入，照寫，尾數變 0
👆
五入（5–9）
尾數係 5、6、7、8、9
→ 入，加 1，尾數變 0

📋 組3 總結

四捨五入三步曲：①截數到目標位 → ②選擇原數或+1 → ③睇尾數（≥5入，<5捨）。記住口號：「四揀不進，五要進」。多做練習就能形成直覺。
