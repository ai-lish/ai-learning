📝 有效數字例子

特殊情況分析 ── 0 的處理與边界案例
📖 特殊情况

⚠️ 0 的處理是關鍵

有效數字最複雜的情况就係 0 的處理——佢可以係有效，也可以唔係，視乎位置而定。

📝 例子展示

📌 各類情况分析

3700
2 個有效數字
若無小數點，尾隨的 0 通常視為非有效（表示截斷位置）
0.0068
2 個有效數字
頭部三個 0 唔算，由第一個非零「6」之前一位「8」為止 → 2 個
2.3700
5 個有效數字
小數點存在，所以末尾的兩個 0 是確定數字（表示精確度）
1.002
4 個有效數字
夾在中間的 0 算入有效（1-0-0-2，共4個）
⚡ 特殊情况判斷
📌 3700 的有效數字——點解係 2 個？

寫成 3700（冇小數點）時，我們一般假設最後兩個 0 是用黎表示位值，而非測量精確度，因此只有 2 個有效數字。

但如果寫成 3.700 × 10³ 或 3.700k，就明確表示有 4 個有效數字（小數點後的 0 是確定數字）。

💡 記憶技巧

「小數點是關鍵信號」—— 有小數點，尾隨 0 算；冇小數點，尾隨 0 多數唔算。

📋 組2 總結

有效數字的特殊情况重点在 0 的處理：頭部 0 不算、夾中 0 算、末尾 0 要睇小數點。遇見 3700 呢類數字時，思考作者想表達的是位值還是精確度，再判斷有效數字數量。
