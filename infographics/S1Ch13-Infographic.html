🔢 有效數字（Significant Figures）

由**第一個非零數字**開始，數到**最後一個確定數字**為止，全部都是有效數字。

單元 13.2 實際應用

⬆️ 上舍入 vs ⬇️ 下舍入

⬆️
上舍入（天台）
ceil(x)
無論如何都
向上進位
例：47÷9=5.22…
→ 6（起碼要6個）
⬇️
下舍入（地板）
floor(x)
無論如何都
向下截斷
例：47÷9=5.22…
→ 5（最多得5個）
🛒
超市購物
上舍入 → 預算充足，唔怕超支
📦
包裝数量
上舍入 → 確保夠數，不會少
💰
最少收益
下舍入 → 保守估計，唔超標
⏰
時間規劃
上舍入 → 預多時間，唔會遲
⚠️ 常犯錯誤

✏️ 立刻試幾題！

Q1：把 3.14159 取至 3 個有效數字，答案係？
✅ 正確！第4位=5，所以入 → 3.14
Q2：超市買 $47.80 貨品，上舍入到元位，實付多少？
✅ 正確！上舍入 → 無論如何都進位 → $48
Q3：0.025600 有多少個有效數字？
✅ 正確！末尾 0 是確定數字 → 5 個（2,5,6,0,0）
Q4：把 2568 四捨五入到十位，答案係？
✅ 正確！個位=8≥5，所以入 → 2570
