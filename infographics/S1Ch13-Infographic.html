🔢 有效數字（Significant Figures）

由**第一個非零數字**開始，到**最後一個確定數字**為止，全部都是有效數字。

✓ 有效數字的例子

2568 → 4 個有效數字

0.0256 → 3 個（開頭兩個 0 不算）

0.025600 → 5 個（末尾 0 是確定數字）

2500 → 2 個（若表示取至百位）

🎯 四捨五入（Rounding）

睇下一位（尾數）是否 ≥ 5，決定是否進位。

0 – 4
👇 捨
不進位，寫低
5 – 9
👆 入
進位，加 1
📝 四捨五入例子

2568 取至十位：→ 睇個位 8 ≥ 5，入 → 2570

2562 取至十位：→ 睇個位 2 < 5，捨 → 2560

3.14159 取 3 個有效數字：→ 第4位是 5，入 → 3.14

單元 13.2 實際應用

⬆️⬇️ 上舍入 vs 下舍入

⬆️ 上舍入（Ceiling）
無論如何都進位
只進不退
⬇️ 下舍入（Floor）
無論如何都不進
只退不進
📝 例子：47 ÷ 9 ≈ 5.22…

上舍入到個位 → 6（哪怕 5.0001 都要入）

下舍入到個位 → 5（哪怕 5.9999 都不入）

🛒 生活應用：超市 price → 上舍入（預多唔預少） │ 估計最低收益 → 下舍入
單元 9 跨單元應用

% 百分數 × 四則混合

百分數 = 每一百份佔幾多份，符號 %

75% = 75/100 = 0.75
百分數 ↔ 小數 ↔ 分數 三者互通
%→小
÷100，去%
⟷
小→%
×100，加%
⟷
%→分
÷100，再約分
📝 折扣例子

書包定價 $120，打 8 折 → 實付 $120 × 80% = $96

成本 $80，利潤率 25% → 售價 $80 × 125% = $100

⚠️ 常犯錯誤

🔍 有效數字 ≠ 只睇位值

✅ 有效數字
由第一個非零數字開始數

例：0.0256 → 3個有效數字

❌ 只睇位值
睇個/十/百位，忽略有效數

例：0.0256 → 唔係「睇千分位」

⚡ 關鍵：面對極大數（地球距離）或極細數（細胞厚度），有效數字比位值更實用！
