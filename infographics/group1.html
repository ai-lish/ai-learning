🔢 有效數字

什麼是有效數字？ ── 由第一個非零數字開始數
📖 核心概念

🔢 有效數字的定義

由 第一個非零數字開始，數到最後一個確定數字為止，全部都是有效數字。

有效數字反映了我們對一個數值的確定程度——唔係位值，而係「有幾多個數字係我哋有信心嘅」。

📝 例子展示

📌 有效數字示意

368
有效數字：3 個
由第一個非零數「3」開始數 → 3、6、8，全部都算
0.0256
有效數字：3 個
頭兩個 0 唔算，由「2」開始 → 2、5、6
35%
有效數字：2 個
由「3」開始 → 3、5，共 2 個有效數字
⚡ 關鍵規則
有效數字計算規則
  • ✅ 非零數字 → 必算
  • ✅ 夾在中間的 0 → 算
  • ✅ 末尾的 0（小數點後）→ 算
  • ❌ 頭部的 0 → 不算
🧠 記憶方法

💡 三字口謎

非
非零就數
夾
夾中就算
頭
頭零唔數

📋 組1 總結

有效數字由第一個非零數字開始數，到最後一個確定數字為止。非零就數，夾中就算，頭零不數。有效數字反映測量的確定程度，是科學與工程計算的基礎概念。
