**中華聖潔會靈風中學　　　中一級數學自學練習**
　　　　　　　　　　　　**練習 17--- 基礎代數**

**例一：**
展開 $(2x+3y)(5x-2y)$

| | $2x$ | $3y$ |
| :--- | :--- | :--- |
| **$5x$** | $(2x)(5x) = +10x^2$ | $(3y)(5x) = +15xy$ |
| **$-2y$** | $(2x)(-2y) = -4xy$ | $(3y)(-2y) = -6y^2$ |

$\therefore (2x+3y)(5x-2y)$
$= 10x^2 + 15xy - 4xy - 6y^2$
$= 10x^2 + 11xy - 6y^2$

---

**例二：**
展開 $(2-y)(-y-5)$

| | $2$ | $-y$ |
| :--- | :--- | :--- |
| **$-y$** | $(2)(-y) = -2y$ | $(-y)(-y) = +y^2$ |
| **$-5$** | $(2)(-5) = -10$ | $(-y)(-5) = +5y$ |

$\therefore (2-y)(-y-5)$
$= -2y + y^2 - 10 + 5y$
$= +y^2 + 3y - 10$

**展開下列各式。**

1. $(x+1)(x+3)$
   $= x^2 + 4x + 3$

2. $(x+1)(x-6)$
   $= x^2 - 5x - 6$

3. $(2x+y)(4x+5y)$
   $= 8x^2 + 14xy + 5y^2$

4. $(x+9y)(3x-2y)$
   $= 3x^2 + 25xy - 18y^2$

5. $(4x-y)(8x-5y)$
   $= 32x^2 - 28xy + 5y^2$

6. $(x-y)(7x-3y)$
   $= 7x^2 - 10xy + 3y^2$

7. $(1-x)(x+3)$
   $= -x^2 - 2x + 3$

8. $(2-6x)(5-x)$
   $= 10 - 32x + 6x^2$
