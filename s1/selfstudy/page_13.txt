**例一：** \hspace{6cm} **例二：**
化簡 $(3x^2 - 2x + 1) + (2x^2 - 4x - 8)$ \hspace{1.5cm} 化簡 $(2y^2 + 6y + 4) - (3 - 4y^2)$
$(3x^2 - 2x + 1) + (2x^2 - 4x - 8)$ \hspace{1.5cm} $(2y^2 + 6y + 4) - (3 - 4y^2)$
$= 3x^2 - 2x + 1 + 2x^2 - 4x - 8$ \hspace{1.5cm} $= 2y^2 + 6y + 4 - 3 + 4y^2$
$= 3x^2 + 2x^2 - 2x - 4x + 1 - 8$ \hspace{1.5cm} $= 2y^2 + 4y^2 + 6y + 4 - 3$
$= 5x^2 - 6x - 7$ \hspace{4.3cm} $= 6y^2 + 6y + 1$

化簡下列各式。

1. $(2x^2 + 5x - 9) + (2x^2 - x + 2)$ \hspace{1.5cm} 2. $(-2y^2 - 4y + 2) + (7y - 3 + 3y^2)$
$= 4x^2 + 4x - 7$ \hspace{4.2cm} $= y^2 + 3y - 1$

3. $(6y^2 + 2y + 7) - (8 - y^2)$ \hspace{2.4cm} 4. $(3z^2 + 5) - (2z^2 + 5z + 1)$
$= 7y^2 + 2y - 1$ \hspace{4.2cm} $= z^2 - 5z + 4$

5. $(7xy - 2xz) + (3xz - 7xy)$ \hspace{2.1cm} 6. $(2x + 3xy) - (6xy + 7x)$
$= xz$ \hspace{5.7cm} $= -5x - 3xy$

7. $(2x^2 - 4xy) + (2y^2 - xy + 7x^2)$ \hspace{1cm} 8. $(14y^2 - xy - 2x^2) - (4y^2 - 5x^2 - 9xy)$
$= 9x^2 - 5xy + 2y^2$ \hspace{3.7cm} $= 10y^2 + 3x^2 + 8xy$
