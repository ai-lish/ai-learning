**練習 21 --- 百分法的基本概念(百分增加 / 減少)**

| 例一： | 例二： | 例三： | 例四： |
| :--- | :--- | :--- | :--- |
| 50 增加 14%後， | 1500 減少 40%後， | 12 增至 14.4， | 15 增至 12， |
| 求增加後的數值。 | 求減少後的數值。 | 求百分增加。 | 求百分減少。 |
| | | | |
| $50 \times (1 + 14\%)$ | $1500 \times (1 - 40\%)$ | $\frac{14.4 - 12}{12} \times 100\%$ | $\frac{12 - 15}{15} \times 100\%$ |
| $= 50 \times (114\%)$ | $= 1500 \times (60\%)$ | $= \frac{2.4}{12} \times 100\%$ | $= \frac{-3}{15} \times 100\%$ |
| $= 50 \times (\frac{114}{100})$ | $= 1500 \times (\frac{60}{100})$ | $= 20\%$ | $= -20\%$ |
| $= 57$ | $= 900$ | | |

**求下列各題中增加或減少後的數值。**

1. 20 小時增加 15%
   $20 (1 + 15\%)$
   $= 23$ 小時

2. 50℃ 增加 30%
   $50^\circ\text{C } (1 + 30\%)$
   $= 65^\circ\text{C}$

3. \$150 減少 10%
   $\$150 (1 - 10\%)$
   $= \$135$

4. 196kg 減少 50%
   $196\text{ kg } (1 - 50\%)$
   $= 98\text{kg}$

5. 從 40 人增加至 60 人，求人數的百分增加。
   $\frac{60 - 40}{40} \times 100\%$
   $= +50\%$

6. 小明身高從 1.5m 長高至 1.62m，求他身高的百分增加。
   $\frac{1.62 - 1.5}{1.5} \times 100\%$
   $= +8\%$

7. 柴油每升的售價從 \$4.5 減至 \$3.6，求售價的百分減少。
   $\frac{3.6 - 4.5}{4.5} \times 100\%$
   $= -20\%$

8. 小強原本體重 50kg, 運動後減輕了 2kg。求他體重的百分減少。
   $\frac{-2}{50} \times 100\%$
   $= -4\%$
