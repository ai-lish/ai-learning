Ch9 直線的坐標幾何

距離公式 · 斜率 · 平行與垂直線 · 分點公式

📏 9.1 兩點之間的距離
水平和鉛垂距離
• 兩點在同一水平線上：距離 = x 坐標的差
• 兩點在同一鉛垂線上：距離 = y 坐標的差
距離公式（畢氏定理）
若 $A(x_1, y_1)$ 和 $B(x_2, y_2)$，則： $$AB = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$
例子： A(-4, -6) 和 B(8, 10)
$AB = \sqrt{(8-(-4))^2 + (10-(-6))^2} = \sqrt{12^2 + 16^2} = \sqrt{400} = 20$
📐 9.2 直線的斜率
斜率公式
若 $A(x_1, y_1)$ 和 $B(x_2, y_2)$，則： $$m = \frac{y_2 - y_1}{x_2 - x_1} \quad (x_1 \neq x_2)$$
斜率的性質
• 由左至右向上傾斜：$m > 0$
• 由左至右向下傾斜：$m < 0$
• 水平線：$m = 0$
• 鉛垂線：斜率不存在
共線點
若 P、Q、R 共線，則：
$PQ$ 的斜率 $= QR$ 的斜率
截距
• $x$-截距：直線與 $x$ 軸相交的 $x$ 坐標
• $y$-截距：直線與 $y$ 軸相交的 $y$ 坐標
∥⊥ 9.3 平行線和垂直線
平行線
$$L_1 \parallel L_2 \implies m_1 = m_2$$
垂直線
$$L_1 \perp L_2 \implies m_1 \times m_2 = -1$$
例子：
• 斜率為 3 的直線，垂直線斜率為 $-1/3$
• 斜率為 $-2/5$ 的直線，垂直線斜率為 $5/2$
📍 9.4 分點
中點公式
若 $M(x, y)$ 是 $A(x_1, y_1)$ 和 $B(x_2, y_2)$ 的中點： $$M = \left(\frac{x_1 + x_2}{2},\ \frac{y_1 + y_2}{2}\right)$$
截點公式（內分點）
若 P 在 AB 上，且 $AP : PB = m : n$： $$P = \left(\frac{nx_1 + mx_2}{m+n},\ \frac{ny_1 + my_2}{m+n}\right)$$
例子： A(0, 4), B(6, 0)，AP:PB = 1:3
$P_x = \frac{3(0) + 1(6)}{4} = \frac{6}{4} = 1.5$
$P_y = \frac{3(4) + 1(0)}{4} = \frac{12}{4} = 3$
✏️ 9.5 坐標幾何作簡單幾何證明
設立坐標系技巧
• 選取其中一個頂點為原點 $(0, 0)$
• 將圖形的邊放置在 $x$ 軸或 $y$ 軸上
• 利用中點公式證明對角線互相平分
常見證明策略
• 平行四邊形：對角線中點相同
• 長方形/菱形：對角線互相垂直或平分
• 等腰三角形：頂點到底邊中點的線垂直於底邊
📝 例題演練
例題 1：距離公式
求 A(-4, -6) 和 B(8, 10) 之間的距離。
▶ 顯示解答
$AB = \sqrt{(8-(-4))^2 + (10-(-6))^2} = \sqrt{144 + 256} = \sqrt{400} = 20$

答案：20
例題 2：中點公式
求 A(-4, -6) 和 B(8, 10) 的中點 M 坐標。
▶ 顯示解答
$M_x = \frac{-4 + 8}{2} = \frac{4}{2} = 2$
$M_y = \frac{-6 + 10}{2} = \frac{4}{2} = 2$

答案：M(2, 2)
例題 3：斜率計算
求通過 P(-2, 3) 和 Q(4, -1) 的直線斜率，並判斷向上或向下傾斜。
▶ 顯示解答
$m = \frac{-1 - 3}{4 - (-2)} = \frac{-4}{6} = -\frac{2}{3}$

斜率為負數，所以由左至右向下傾斜。

答案：m = -2/3
例題 4：平行線判斷
直線 L₁ 斜率為 3/4，直線 L₂ 斜率為 0.75。兩線是否平行？
▶ 顯示解答
$m_1 = 3/4 = 0.75$
$m_2 = 0.75$
$m_1 = m_2$，所以 L₁ ∥ L₂

答案：是的，兩線平行
例題 5：垂直線斜率
一直線斜率為 2，求與它垂直的直線斜率。
▶ 顯示解答
$m_1 \times m_2 = -1$
$2 \times m_2 = -1$
$m_2 = -1/2$

答案：-1/2
例題 6：內分點坐標
A(0, 4) 和 B(6, 0)，若 AP:PB = 1:3，求 P 坐標。
▶ 顯示解答
$P_x = \frac{3(0) + 1(6)}{1+3} = \frac{6}{4} = 1.5$
$P_y = \frac{3(4) + 1(0)}{1+3} = \frac{12}{4} = 3$

答案：P(1.5, 3)
挑戰題：幾何證明
長方形 OABC，O(0,0)，A(6,0)，B(6,4)，C(0,4)。證明 OB 和 AC 互相平分。
▶ 顯示解答
步驟 1：求 OB 中點
$M_{OB} = \left(\frac{0+6}{2},\ \frac{0+4}{2}\right) = (3, 2)$

步驟 2：求 AC 中點
$M_{AC} = \left(\frac{6+0}{2},\ \frac{0+4}{2}\right) = (3, 2)$

結論：兩對角線中點相同，故 OB 和 AC 互相平分。∎
