Chapter roadmap本章學習地圖

Start with summation notation, understand the logic of induction, and then apply the method to finite sequence sums.先掌握求和符號，再理解數學歸納法的邏輯，最後把方法應用在有限數列的求和公式。

1. Summation Notation1. 求和符號

Use Σ to write a patterned list of terms compactly, and learn to expand, evaluate, and split a sum.用 Σ 把一串有規律的項目寫得簡潔，並學會展開、計算和拆分求和式。

Σr=mn ar = am + am+1 + ··· + an

2. Principle of Mathematical Induction2. 數學歸納法原理

Prove the first case, then prove that case k implies case k + 1; together, these steps reach every positive integer.先證明第一個情況，再證明「第 k 個成立會令第 k + 1 個也成立」，便能推到所有正整數。

P(1) true
P(k) ⇒ P(k + 1)
∴ P(n) true for all n ∈ ℤ+

3. Finite Sequence Sums3. 有限數列求和

Apply induction to arithmetic, odd-number, square-number, and other finite sequence sums, checking each algebraic step.把歸納法應用到等差、奇數、平方數及其他有限數列的求和公式，並檢查每個推導步驟。

1 + 3 + 5 + ··· + (2n − 1) = n2
Important distinction:重要分別： Checking a few values can suggest that a statement is true, but it cannot prove a claim for infinitely many positive integers. Induction requires both the base case and the inductive step.代入幾個數值只能支持「可能成立」，不能證明命題對無限多個正整數都成立。歸納法需要同時完成 base case 和 inductive step。

By the end of this chapter, you should be able to:完成本章後，你應能夠：

  • Read and write Σr=mn ar, and count the n − m + 1 terms correctly.讀寫 Σr=mn ar，並正確數出共有 n − m + 1 項。
  • Write a mathematical-induction proof using five clear steps.用五個清晰步驟寫出數學歸納法證明。
  • Use known formulas to calculate and verify finite sequence sums.利用已知公式，計算及驗證有限數列的和。
  • Distinguish checking examples from proving a statement for every positive integer.分辨「驗證幾個例子」與「對所有正整數的證明」。

7 · Evidence is not proof7 · 例子不是證明

Examples suggest; proof establishes例子提示規律，證明確立命題

Checking n = 1, 2, 3 is useful evidence. It does not test the infinitely many positive integers still waiting.檢查 n = 1、2、3 是有用的證據，但仍未測試其餘無限多個正整數。

A pattern is a question. Induction is the answer.規律是一個問題；歸納法就是答案。

Two kinds of confidence兩種不同信心

✓
Examples例子n = 1, 2, 3 work.n = 1、2、3 都成立。
∞
Proof證明Every positive integer is connected.所有正整數都連接起來。
The missing idea is the link P(k) ⇒ P(k + 1). It carries truth from one arbitrary step to the next.欠缺的關鍵是連接 P(k) ⇒ P(k + 1)，把一個任意步驟的成立推到下一步。

8 · Build the bridge8 · 建立橋樑

A start and a reliable link起點與可靠的推進

Mathematical induction needs two ideas: start at P(1), then show that any true P(k) leads to true P(k + 1).數學歸納法需要兩個想法：由 P(1) 開始，再證明任何成立的 P(k) 都會令 P(k + 1) 成立。

Both pieces matter: no start means no first domino; no link means no journey.兩部分都重要：沒有起點就沒有第一塊骨牌，沒有連接就不能向前推進。

The five induction steps歸納法五步

We will prove P(n): 1 + 3 + 5 + ··· + (2n − 1) = n2 one step at a time.以命題 P(n): 1 + 3 + 5 + ··· + (2n − 1) = n2 為例，逐步檢查證明。

1

Define the proposition P(n)定義命題 P(n)

State clearly what must be proved and specify the domain: n is a positive integer.清楚寫出要證明的命題，以及 n 的範圍：n 是正整數。

P(n): 1 + 3 + 5 + ··· + (2n − 1) = n2
2

Prove P(1) (the base case)證明 P(1) 成立（base case）

Substitute n = 1 into both sides. Both sides equal 1, so P(1) is true.把 n = 1 代入左右兩邊，兩邊都等於 1，所以 P(1) 成立。

LHS = 1　　RHS = 12 = 1
3

Assume P(k) is true假設 P(k) 成立

Let k be an arbitrary positive integer and temporarily assume that the kth proposition is true. This assumption is used only to derive the next step.令 k 是一個任意正整數，並暫時假設第 k 個命題成立。這個假設只用於推導下一步。

1 + 3 + ··· + (2k − 1) = k2
4

Prove P(k) ⇒ P(k + 1)由 P(k) 推出 P(k + 1)

Add the next term, 2k + 1, to both sides of P(k), then simplify to obtain (k + 1)2.在 P(k) 的等式兩邊加上下一項 2k + 1，整理後得到 (k + 1)2。

k2 + (2k + 1) = k2 + 2k + 1 = (k + 1)2
5

State the conclusion寫出結論

Because P(1) is true and P(k) implies P(k + 1), the principle of mathematical induction gives P(n) for every positive integer n.因為 P(1) 成立，而且 P(k) 成立會推出 P(k + 1) 成立，所以根據數學歸納法，P(n) 對所有正整數 n 成立。

∴ 1 + 3 + 5 + ··· + (2n − 1) = n2　for all n ∈ ℤ+

The base case is like knocking down the first domino; the inductive step guarantees that each fallen domino knocks down the next one.base case 像推倒第一塊骨牌；inductive step 保證每一塊倒下都會推倒下一塊。
