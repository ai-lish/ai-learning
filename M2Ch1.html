Mathematical Induction

本章學習地圖

先掌握求和符號，再理解數學歸納法的邏輯，最後把方法應用在有限數列的求和公式。

1. Summation Notation

用 Σ 把一串有規律的項目寫得簡潔，並學會展開、計算和拆分求和式。

Σr=mn ar = am + am+1 + ··· + an

2. Principle of Mathematical Induction

證明第一個情況，再證明「第 k 個成立會令第 k + 1 個也成立」，便能推到所有正整數。

P(1) true
P(k) ⇒ P(k + 1)
∴ P(n) true for all n ∈ ℤ+

3. Finite Sequence Sums

把歸納法應用到等差、奇數、平方數及其他有限數列的求和公式，並檢查每個推導步驟。

1 + 3 + 5 + ··· + (2n - 1) = n2
重要分別：代入幾個數值只能支持「可能成立」，不能證明命題對無限多個正整數都成立。歸納法需要同時完成 base case 和 inductive step。

完成本章後，你應能夠

  • 讀寫 Σr=mn ar，並正確數出共有 n - m + 1 項。
  • 用五個清晰步驟寫出數學歸納法證明。
  • 利用已知公式，計算及驗證有限數列的和。
  • 分辨「驗證幾個例子」與「對所有正整數的證明」。

Σ 求和符號

Σ 的下標是起點，上標是終點，右邊的通項告訴我們每一項如何計算。

Σr=mn ar = am + am+1 + ··· + an
部分意思例子
Σ把指定範圍的項目相加。Greek letter sigma
r求和的 dummy variable，可改名為 i 或 j。不改變求和結果
m求和起點。r = 2
n求和終點。r = 6
ar每一項的通項。ar = r2

常用性質（同一個求和範圍）：

  • Σ c = c(n - m + 1)：常數一共出現 n - m + 1 次。
  • Σ (ar + br) = Σ ar + Σ br：可逐項拆開。
  • Σ (c ar) = c Σ ar：常數因子可提出。
  • Σ (arbr) ≠ (Σ ar)(Σ br)：逐項相乘一般不能拆成兩個和的乘積。

歸納法五步

以命題 P(n): 1 + 3 + 5 + ··· + (2n - 1) = n2 為例，逐步檢查證明。

1

定義命題 P(n)

清楚寫出要證明的命題，以及 n 的範圍：n 是正整數。

P(n): 1 + 3 + 5 + ··· + (2n - 1) = n2
2

證明 P(1) 成立（base case）

把 n = 1 代入左右兩邊，兩邊都等於 1，所以 P(1) 成立。

LHS = 1　　RHS = 12 = 1
3

假設 P(k) 成立

令 k 是一個正整數，並暫時假設第 k 個命題成立。這個假設只用於推導下一步。

1 + 3 + ··· + (2k - 1) = k2
4

由 P(k) 推出 P(k + 1)

在 P(k) 的等式兩邊加上下一項 2k + 1，整理後得到 (k + 1)2。

k2 + (2k + 1) = k2 + 2k + 1 = (k + 1)2
5

寫出結論

因為 P(1) 成立，而且 P(k) 成立會推出 P(k + 1) 成立，所以根據數學歸納法，P(n) 對所有正整數 n 成立。

∴ 1 + 3 + 5 + ··· + (2n - 1) = n2　對所有 n ∈ ℤ+

骨牌效果

base case 像推倒第一塊骨牌；inductive step 保證每一塊倒下都會推倒下一塊。

1234567…
