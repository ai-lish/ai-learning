# 進制（Number Bases）仿題系統 — 規劃與測試文檔

## 📌 題型分類（T1–T7）

### T1 — HEX位置表示法（直接讀值）
- **關鍵技能：** 理解 HEX 每一位的值 = digit × base^n
- **題目形式：** `BC000DE000000_{20}` → 計算十進制值
- **代表年份：** 2012Q33, 2013Q33, 2016Q33

### T2 — 指數表達式化簡（多位進制冪之和）
- **關鍵技能：** a×b^c + b^d + e×b^f - b^f
- **題目形式：** `2 × 4^3 + 4^8 + 6 × 4^2 - 4^2 =`
- **代表年份：** 2014Q34, 2015Q33

### T3 — 跨進制轉換（混合進制）
- **關鍵技能：** 8進制 → 2進制轉換，理解進位
- **題目形式：** `8^3 + 8^19 =`（結果以二進制表示）
- **代表年份：** 2017Q32

### T4 — 二進制→十進制
- **關鍵技能：** 由右數位，指數=位位置
- **題目形式：** `100110000010110_2 =`
- **代表年份：** 2019Q33

### T5 — HEX位置表示法（變體）
- **關鍵技能：** 同T1但數字結構不同，尾部有特殊位
- **題目形式：** `B000000000000030_{14} =`
- **代表年份：** 2020Q31

### T6 — HEX混合算術
- **關鍵技能：** 理解 HEX 係數（E=14, B=11等）+ 進位問題
- **題目形式：** `14×16^15 + 17×16^14 + 16^2 + 17`（結果為 HEX 字串）
- **代表年份：** 2021Q32（答案=D）

### T7 — HEX字符串→Base-4表達式
- **關鍵技能：** HEX→Base-4→十進制
- **題目形式：** `299×4^22 + 205×4^14 + 14 =`
- **代表年份：** 2022Q34

## 🚫 常見陷阱分析（ABCD Distractors）

### T1 陷阱（HEX位置表示法）
| 陷阱 | 描述 | 計算方式 |
|------|------|---------|
| A | A-F值錯（A→B, E→F，即每個HEX字母值+1） | 將所有HEX字母值+1，重新計算 |
| B | 位數錯（13位當12位 → 最高指數-1） | digitStr前加1，減少一位 |
| C | 兩位HEX分開讀（BC→B+C而非B×16+C=188） | 答案 + 16^(n-2) |

### T2 陷阱（指數表達式）
| 陷阱 | 描述 | 計算方式 |
|------|------|---------|
| A | ×b^n係數忽略（5×2^3寫成2^3=1000，應為1010） | 只保留b^c部分，忽略a×b^c |
| B | 十進制數當十六進制（11以為是B=11_{16}） | 數字直接以十進制加入，未乘進制冪 |
| C | -b^f衝突未處理（+e×b^f與-b^f抵消為(e-1)×b^f） | 係數從a變成a-1 |

### T3 陷阱（跨進制轉換）
| 陷阱 | 描述 | 計算方式 |
|------|------|---------|
| A | 8^n直接寫成後面n個0（忽略進位） | 8^19 → 1後19個0 = 10^19（錯誤！） |
| B | 8^n當普通指數，唔做base-2轉換 | 直接以8為底的結果 |
| C | 8^a+8^b進位遺漏（8^a變成8×8^a） | 冪次增加1 |

### T4 陷阱（二進制→十進制）
| 陷阱 | 描述 | 計算方式 |
|------|------|---------|
| A | 由左數位（位0=1而非0，指數全部多1） | 錯誤指數 = n-1-i → i+1 |
| B | 最後位值計算錯（+1或-1） | 答案 ±1 |
| C | 首位當2^n而非2^(n-1) | 首位指數多1 |

### T5 陷阱（HEX位置變體）
| 陷阱 | 描述 | 計算方式 |
|------|------|---------|
| A | A值=10而非11正確，B=11而非12 | leading digit值-1 |
| B | 位數數錯（n位→最高次方為n而非n-1） | 答案 + base^(len-1) |
| C | 尾部30_{16}位置錯（48_{10}當成其他位值） | 答案 + 48×base^(len-3) |

### T6 陷阱（HEX混合算術）
| 陷阱 | 描述 | 計算方式 |
|------|------|---------|
| A | B vs D混淆（進位後B=10零，D=11零） | p+q-16進位，導致係數變化 |
| B | HEX係數值錯（E=14以為是13，A=10以為是11） | p-1 或 q-1 |
| C | 指數錯1位（16^c當成16^(c-1)或16^(c+1)） | c → c-1 或 c+1 |

### T7 陷阱（HEX→Base4表達式）
| 陷阱 | 描述 | 計算方式 |
|------|------|---------|
| A | 位數數錯（13位當12位，首位指數-1） | a7 → a7+1 |
| B | e1指數錯（正確e1=22，錯誤e1=23） | e1 → e1+1 |
| C | b7係數錯（正確b7=205，錯誤b7=206） | b7 → b7+1 |

## 🧪 Copilot 測試指令

### 測試目標
1. 驗證 10 條題目的「重做類似題」按鈕正常運作
2. 驗證 trap-based distractor 選項正確計算
3. 驗證不同變量組合生成的題目與答案一致

### 測試步驟
1. 打開 `dse-practice-p2.html`
2. 揀選「進制」課題filter
3. 點擊任一題目的「🔄 重做類似題」
4. 檢查：
   - 選項是否為4個不同數值
   - 正確答案是否在選項中
   - distractor是否基於真實陷阱計算（並非隨機）
   - 選項隨機排列（正確答案唔永遠係A）

### 預期行為
- 每個題型產生的distractor具有明顯差異（非±1隨機誤差）
- 學生選擇錯誤答案後，顯示該題型的「陷阱解說」
- 答案計算與題目變量一致

## 🔧 trapDistractors() JavaScript 函數位置

**檔案：** `dse-practice-p2.html`  
**行數：** ~612–778  
**調用：** `showRetryQuestion()` 函數，基於 `template.traps[0].type` 路由

```
template.traps[0].type → trapDistractors(pattern, gen, vars, question, ans)
  T1 → parseBase(hexStr+1) / 1+digitStr / ans+16^(len-2)
  T2 → pow(b,c) / numVal+pow / (a-1)*pow
  T3 → 10^exp / pow(8,exp) / pow(base,exp+1)
  T4 → sum(2^(i+1)) / ans±1 / ans-2^(n-1)+2^n
  T5 → ans-(lVal-1)*base^(len-1) / ans+base^(len-1) / ans+48*base^(len-3)
  T6 → carry-based / (p-1)*16^c / p*16^(c-1)
  T7 → (a7+1)*4^e1 / a7*4^(e1+1) / (b7+1)*4^e2
```
