關鍵進制關係

  • 8 = 2³
  • 16 = 2⁴
  • 每 3 位 2 進制 = 1 位 8 進制
  • 每 4 位 2 進制 = 1 位 16 進制

🗂️ 題型分類（T1–T6）

T1 16進制 → 指數展開式 出現 4 次：2012、2013、2016、2022
解題框架：
  1. 數總位數 → 最高次方 = $16^{n-1}$
  2. 每個 HEX 數值轉 DEC（A=10, B=11 … F=15）
  3. 特別注意「兩位 HEX」（如 BC、CD）係聯合成一個數值，唔係分開讀

示範：2022 Q34 — $12B00CD000000E_{16}$

位數：13位 → 最高次方 = $16^{11}$
$12B = 1×16² + 2×16¹ + 11 = 256 + 32 + 11 = 299$
$CD = 13×16 + 14 = 208 + 14 = 222$
…（中間 000000 皆為 0）
$E = 14$

答案：$299 × 16^{11} + 222 × 16^6 + 14$

T2 算式結果 → 2進制寫出 出現 2 次：2014、2015
解題框架：
  1. 將所有乘冪項拆成獨立 2 的次方
  2. 注意 $-2^n$ 係「減去」而非「負數」
  3. 特別注意係數（如 $5 × 2^3 = 1010_2$ 而非 0101！）

示範：2014 Q34 — $7 × 2^{10} + 2^8 + 5 × 2^3 - 2^3$

$7 × 2^{10} = 111₂ × 2^{10} = 11100000000000_2$
$2^8 = 100000000_2$
$5 × 2^3 = 101_2 × 2^3 = 101000_2$
$- 2^3 = -1000_2$（與 $5×2^3$ 衝突！）

整理後：$111100010000_2$ → 答案 B

示範：2015 Q33 — $11 + 2^6 + 2^{10} + 2^{11}$

⚠️ 小心：11 係十進制 11（即 3 = 11₂）
唔係十六進制 B！

$11_{10} = 11_2$
$2^6 = 1000000_2$
$2^{10} = 10000000000_2$
$2^{11} = 100000000000_2$

合併：$110001001011_2$ → 答案 A

陷阱例子涉及年份
$5 × 2^3$ → 誤當 0101（正確係 1010）20141次

T3 跨進制轉換（8→16） 出現 1 次：2017
解題框架：
  1. 關鍵關係：$8 = 2^3$，$16 = 2^4$
  2. 將所有底數統一成 2 的次方
  3. 注意進位（carry）問題

示範：2017 Q32 — $8^3 + 8^{19}$

$8^3 = (2^3)^3 = 2^9 = 512_{10} = 200_{16}$
$8^{19} = (2^3)^{19} = 2^{57}$

$2^{57}$ 轉 16 進制：每 4 個二進制位 = 1 個十六進制位
$57 ÷ 4 = 14$ 餘 1 → 所以 $2^{57} = E00...000_{16}$（共14位）

$512 + E00...000$ 複雜進位後：答案 D = $2000000000000200_{16}$

陷阱位

陷阱例子涉及年份
$8^{19}$ 直接寫成 1 後面 19 個 0，忽略進位2017A/B/C1次
T4 2進制 → 指數展開式 出現 1 次：2019
解題框架：
  1. 由右至左數位（從 0 開始！）
  2. 找出所有 1 的位置
  3. 化成「某係數 × 2ⁿ + 常數」形式

示範：2019 Q33 — $100110000010110_2$

由右至左數位（從 0 開始）：
位 11: 1 ｜ 位 10: 0 ｜ 位 9: 0 ｜ 位 8: 1 ｜ 位 7: 1 ｜ 位 6: 0
位 5: 0 ｜ 位 4: 0 ｜ 位 3: 0 ｜ 位 2: 1 ｜ 位 1: 1 ｜ 位 0: 0

1 的位置：11, 10, 8, 4, 2, 1
$= 2^{11} + 2^{10} + 2^8 + 2^4 + 2^2 + 2^1$
$= 2048 + 1024 + 256 + 16 + 4 + 2 = 3350$
$= 19 × 2^{10} + 22$ → 答案 A

陷阱位

陷阱例子涉及年份
由左至右數位（從 1 開始）→ 指數全部多 12019B/C/D1次
位值相加出錯2019B1次
T5 16進制 → 2進制混合算術 出現 1 次：2020
解題框架：
  1. 只須關注低位（尾幾位）來確認答案
  2. B = 1011₂，最低 4 位 = 0011 = 3
  3. 每個 HEX 位 = 4 個二進制位

示範：2020 Q31 — $B000000000000030_{16}$

$B = 1011_{16} = 11_{10}$
尾部 $30_{16} = 0011 0000_2 = 48_{10}$
B 後面 12 個 0（即 48 bits 位置）

$= B × 16^{12} + 30$
$= 11 × 2^{48} + 48$
$= 11 × 2^{60} + 48$
（12個十六進位 = 48個二進制位）

→ 答案 B（$11 × 2^{60} + 48$）

⚠️ 常見學生錯誤模式

  • 1A-F 死記變 A=11（緊張時常見，溫書時畫 HEX 表）
  • 2數位數由 1 開始數（應由 0 開始，右邊第一位永遠係 $2^0$）
  • 3$5 × 2^3$ 唔識拆成 1010（5 = 101₂，×8 即整體左移3位）
  • 4忽略 $-2^3$ 與 $5 × 2^3$ 的衝突（同一位置既加又減）
  • 5進制轉換時忘記進位（特別係跨進制混合題）
