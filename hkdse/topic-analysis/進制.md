## 二、題目類型分類

### T1｜16進制 → 指數展開式（出現 4 次：2012、2013、2016、2022）

**解題框架：**
1. 數總位數 → 最高次方 = $16^{n-1}$
2. 每個 HEX 數值轉 DEC（A=10, B=11, C=12, D=13, E=14, F=15）
3. 特別注意「兩位 HEX」（如 BC、12B）係聯合成一個數值，唔係分開讀

**示範：2022 Q34 — `$12B00CD000000E_{16}$`**
```
位數：13位 → 最高次方 = 16^11

12B = 1×16² + 2×16¹ + 11 = 256 + 32 + 11 = 299
00  = 0
CD  = 13×16 + 14 = 208 + 14 = 222
...（中間 000000 皆為 0）
E   = 14

答案：299 × 16^11 + 222 × 16^6 + 14 × 16^0
```

**選項陷阱：**
| 陷阱 | 例子 | 涉及年份 |
|------|------|----------|
| A-F 數值記錯（A=11 而非 10；E=15 而非 14） | 2012、2013、2020 | 4次 |
| 數位數錯 → 指數多1或少1 | 2012B、2013C、2016C、2022C | 4次 |
| 兩位 HEX 拆開當獨立數值（如 BC → B=11, C=12） | 2016B | 1次 |

### T2｜算式結果 → 2進制寫出（出現 2 次：2014、2015）

**解題框架：**
1. 將所有乘冪項拆成獨立 2 的次方
2. 注意 $-2^n$ 係「減去」而非「負數」
3. 特別注意係數（如 $5 \times 2^3 = 1010_2$ 而非 0101！）

**示範：2014 Q34 — `$7 \times 2^{10} + 2^8 + 5 \times 2^3 - 2^3$`**
```
7 × 2^10 = (111)₂ × 2^10 = 11100000000000₂
2^8       = 100000000₂
5 × 2^3   = 101₀₀₀₂
- 2^3     = -1000₂（衝突！）

實際分組：7×2^10 → 111 0000 0000 00
          + 2^8  →   1 0000 0000
          + 4×2³ →     1 000
          （減2³抵消）
整理後：111100010000₂ → 答案 B
```

**示範：2015 Q33 — `$11 + 2^6 + 2^{10} + 2^{11}$`**
```
小心：11 係十進制 11（即 3 = 11₂）
      唔係十六進制 B！

11₁₀  = 11₂
2^6   = 100 0000₂（對齊至位6）
2^10  =     1 0000 0000 0000（對齊至位10）
2^11  = 1 0000 0000 0000 0（對齊至位11）

合併：110001001011₂ → 答案 A
```

**選項陷阱：**
| 陷阱 | 例子 | 涉及年份 |
|------|------|----------|
| $5 \times 2^3$ → 誤當 0101（正確係 1010） | 2014 | 1次 |
| 十進制 11 當成十六進制 B 或二進制 1011 | 2015B/C | 1次 |
| $-2^3$ 冇處理解決方案衝突 | 2014 | 1次 |

### T3｜跨進制轉換（出現 1 次：2017）

**解題框架：**
1. 關鍵關係：$8 = 2^3$，$16 = 2^4$
2. 將所有底數統一成 2 的次方
3. 注意進位（carry）問題

**示範：2017 Q32 — `$8^3 + 8^{19}$`**
```
8^3   = (2^3)^3 = 2^9  = 512₁₀ = 200₁₆
8^19  = (2^3)^19 = 2^57

2^57 轉 16 進制：
每 4 個二進制位 = 1 個十六進制位
57 ÷ 4 = 14 餘 1
所以 2^57 = 1 × 2^56 = E00...000₁₆（共14位）

512 + E00...000 → 由於 E...000 尾三位為 0
512 (200) + E00...000 = E00...200₁₆
但需進位 → E00...200 + 200 = E00...400...需再進位
複雜計算後：答案 D = 2000000000000200₁₆
```

**選項陷阱：**
| 陷阱 | 例子 | 涉及年份 |
|------|------|----------|
| $8^{19}$ 直接寫成 1 後面 19 個 0，忽略進位 | 2017A/B/C | 1次 |

---

### T4｜2進制 → 指數展開式（出現 1 次：2019）

**解題框架：**
1. 由右至左數位（從 0 開始！）
2. 找出所有 1 的位置
3. 化成「某係數 × 2^n + 常數」形式

**示範：2019 Q33 — `$100110000010110_2$`**
```
位置由右至左（從 0 開始）：
位 11: 1
位 10: 0
位 9:  0
位 8:  1
位 7:  1
位 6:  0
位 5:  0
位 4:  0
位 3:  0
位 2:  1
位 1:  1
位 0:  0

1 的位置：11, 10, 8, 4, 2, 1

2^11 + 2^10 + 2^8 + 2^4 + 2^2 + 2^1
= 2048 + 1024 + 256 + 16 + 4 + 2
= 3350

用最大公因數簡化：
= 19 × 2^10 + 22  → 答案 A
```

**選項陷阱：**
| 陷阱 | 例子 | 涉及年份 |
|------|------|----------|
| 由左至右數位（從 1 開始）→ 指數全部多 1 | 2019B/C/D | 1次 |
| 位值相加出錯 | 2019B | 1次 |

### T5｜16進制 → 2進制混合算術（出現 1 次：2020）

**解題框架：**
1. 只須關注低位（尾幾位）來確認答案
2. B=1011₂，最低 4 位 = 0011 = 3
3. 每個 HEX 位 = 4 個二進制位

**示範：2020 Q31 — `$B000000000000030_{16}$`**
```
B = 1011₁₆ = 1011₂
尾部 30₁₆ = 0011 0000₂ = 48₁₀

B 後面 12 個 0（即 48 bits 位置）

B000000000000030
= B × 16^12 + 30
= 11 × 2^48 + 48     ← 16^12 = (2^4)^12 = 2^48
= 11 × 2^60 + 48     ← 48 bits = 2^60
                      （12個十六進位 = 48個二進制位）

答案：B（11 × 2^60 + 48）
```

**選項陷阱：**
| 陷阱 | 例子 | 涉及年份 |
|------|------|----------|
| A=10（正確係 11） | 2020A | 1次 |
| 位數數錯（$2^{64}$ 而非 $2^{60}$） | 2020C | 1次 |

### T6｜16進制混合算術（出現 1 次：2021）

## 五、關鍵進制關係

```
2 進制：  0, 1
8 進制：  0-7  → 每 3 位 2 進制 = 1 位 8 進制
16 進制： 0-F  → 每 4 位 2 進制 = 1 位 16 進制

關鍵轉換：
8  = 2³
16 = 2⁴
```

## 六、教學建議

### 練習層次建議

**Level 1（基礎）** — 純位值轉換
- HEX → DEC
- 2進制 → 指數展開式
- 參考：2019 Q33

**Level 2（核心）** — 獨立多位 HEX 展開
- 多位 HEX → $n \times 16^k$ 形式
- 注意 A-F 數值
- 參考：2012 Q33、2013 Q33

**Level 3（進階）** — 兩位 HEX 當整體
- BC、CD、12B 等係聯合成一個數值
- 參考：2016 Q33、2022 Q34

**Level 4（綜合）** — 跨進制 + 進位
- 涉及 8/16 混合
- 注意進位問題
- 參考：2017 Q32

### 常見學生錯誤模式
1. A-F 死記變 A=11（緊張時常見）
2. 數位數由 1 開始數（應由 0）
3. $5 \times 2^3$ 唔識拆成 1010
4. 忽略 $-2^3$ 與 $5 \times 2^3$ 的衝突
5. 進制轉換時忘記進位
