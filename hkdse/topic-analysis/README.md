## 分析結構

每個課題分析包含：

1. **歷屆試題總覽** — 年份、題號、題型分類、做對率
2. **題目類型分類** — 按解題方法分組
3. **選項分析 & 陷阱位** — 逐題分析 ABCD 考核點
4. **高頻陷阱排行榜** — 最容易中嘅陷阱
5. **備忘/速查表** — HEX 數值表等
6. **教學建議** — 練習層次建議
