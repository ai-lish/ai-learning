# Infographic Editor Tool - Research Prompt for Gemini

## 目標
幫忙研究及建議一個網頁工具，用於共同制定 Infographic 初稿。

## 背景
- 用戶（老師）需要製作教育類 Infographic 資訊圖
- 目前缺乏合適工具，需要長時間使用
- 用戶主要使用手機操作
- 需要與 AI 助手（我）協作

## 需求
用戶需要一個網頁工具，具備以下功能：

### 1. 基本功能
- 可以添加、移動、調整大小的元素（文字方塊、卡片、圖片）
- 每個元素有 x, y, width, height 座標
- 導出功能，輸出 JSON 格式的座標和內容

### 2. 元素類型
- 標題欄
- 欄目標題（加法原理、減法原理等）
- Case 卡片（A、B、C 等）
- 計算區域（數學算式）
- 答案按鈕
- 分隔線

### 3. 協作功能
- 可以上傳背景圖片作為參照
- 實時預覽效果
- 保存/載入項目（localStorage 或其他方式）

### 4. 手機友好
- 響應式設計
- 適合觸控操作
- 直覺的拖放介面

## 請求
請幫忙建議：
1. 現有的類似工具（可參考的）
2. 這個工具的技術架構建議
3. UI/UX 設計重點
4. 關鍵功能優先級建議
5. 任何其他有用嘅建議

## 輸出格式
以結構化方式輸出建議，方便轉化為實際開發計劃。
