# AI Learning public deployment

This repository contains only the public deployment output for `ai-lish/ai-learning`.
The source of truth is the private `math-lish/ai-learning` repository.

The current output is a reviewed public interface. The teacher workload page is
a self-contained browser tool copied from the private `math-lish/local-tools`
source; source spreadsheets, PDFs, snapshots, parser documents and backend code
are not published here.

Public entry: `https://ai-lish.github.io/ai-learning/local-tools/`

The current teacher-tool artifact is sourced from private
`math-lish/local-tools` revision `8235817d426c0b4188c7b8506cd7087bacee90d8`.

The teacher tool processes selected files in the browser and provides download
or clipboard export. It does not upload source files or write to a backend.
