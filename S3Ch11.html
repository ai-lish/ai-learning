Ch11 概率簡介

概率 · 樣本空間 · 樹形圖 · 期望值

🎲 11.1 概率的基本概念
描述機會的詞語
• 不可能 → 概率 = 0
• 很少 / 機會很小 → 概率接近 0
• 有時 → 概率約 0.5
• 經常 / 機會很大 → 概率接近 1
• 必然 → 概率 = 1
概率的定義
概率（Probability）是一個介乎 0 與 1 之間（包括 0 和 1）的數值，用以量度事件發生的機會。
概率的範圍
對於任何事件 $E$：$$0 \leq P(E) \leq 1$$ • 必然事件：$P = 1$
• 不可能事件：$P = 0$
📋 11.2 樣本空間與事件
基本詞彙
• 樣本空間（Sample space）：一個活動中所有可能結果的組合，記作 $S$
• 事件（Event）：我們感興趣的可能結果組成的事件，記作 $E$
• 合適結果（Favourable outcome）：有利於事件發生的結果
例子：擲骰子
投擲一枚均稱骰子一次：
• 樣本空間 $S = \{1, 2, 3, 4, 5, 6\}$（共 6 個可能結果）
• 事件 $E$ = 「擲得奇數」
• 合適結果 = 1、3、5（共 3 個）
📐 11.3 理論概率
等可能性假設
當一個活動的所有可能結果發生的機會都相等（equally likely）時，可以計算理論概率。
概率公式
$$P(E) = \frac{\text{事件 } E \text{ 的合適結果的數目}}{\text{可能結果的總數}}$$
例子：骰子
擲骰子，「擲得 3」的概率：
$$P(\text{擲得3}) = \frac{1}{6}$$
例子：彈珠袋
袋中有 4 粒紅彈珠和 2 粒藍彈珠，隨機抽出一粒：
• 可能結果總數 = $4 + 2 = 6$
• 抽出紅彈珠的概率 = $\frac{4}{6} = \frac{2}{3}$
• 抽出藍彈珠的概率 = $\frac{2}{6} = \frac{1}{3}$
例子：字母概率
從「PAPAYA」中隨機選出一個字母：
• 總字母數 = 6
• $P(Y) = \frac{1}{6}$（Y 出現 1 次）
• $P(A) = \frac{3}{6} = \frac{1}{2}$（A 出現 3 次）
🌳 11.4 樹形圖與數表
為什麼要用樹形圖/數表？
當遇到涉及兩個或以上步驟的複雜事件時，單憑想像容易遺漏或重複。使用樹形圖或數表可以有系統地列出所有可能結果。
例子：拋硬幣兩次
第二次：正 第二次：反
第一次：正 正、正 正、反
第一次：反 反、正 反、反
共 4 個可能結果：HH、HT、TH、TT
計算「一正一反」的概率
合適結果：HT、TH（2 個）
$$P(\text{一正一反}) = \frac{2}{4} = \frac{1}{2}$$
例子：同時擲兩枚硬幣
同時擲兩枚硬幣，相當於獨立拋兩次。用樹形圖列出所有可能結果，計算所需事件的概率。
📊 11.5 期望值
期望次數
若事件 $A$ 的概率是 $p$，進行 $n$ 次試驗：
期望次數 = $np$
例子：拋硬幣
拋硬幣 10,000 次，擲得正面的期望次數：
$$np = 10{,}000 \times \frac{1}{2} = 5{,}000 \text{ 次}$$
數值期望值
若有 $m$ 個可能結果，數值為 $v_1, v_2, ..., v_m$，概率為 $p_1, p_2, ..., p_m$：
$$\text{期望值} = v_1p_1 + v_2p_2 + ... + v_mp_m$$
例子：抽硬幣
袋中有 \$2 和 \$5 硬幣各一枚，隨機抽出一枚：
• $P(\$2) = 0.5$，$P(\$5) = 0.5$
• 期望值 $= \$2 \times 0.5 + \$5 \times 0.5 = \$1 + \$2.5 = \$3.5$
公平遊戲
在一個遊戲中，若「所得的期望值 = 付出的金額」，則該遊戲是公平的。
📝 例題演練
例題 1：基本概率計算
一袋中有 3 粒紅球和 7 粒藍球，隨機抽出一球。求抽出紅球的概率。
▶ 顯示解答
合適結果 = 3（紅球數目）
可能結果總數 = $3 + 7 = 10$

$P(\text{紅球}) = \frac{3}{10}$

答案：$\frac{3}{10}$
例題 2：擲骰子
投擲一枚均稱骰子一次。求下列事件的概率：
(a) 擲得 4
(b) 擲得奇數
▶ 顯示解答
樣本空間 $S = \{1,2,3,4,5,6\}$，共 6 個可能結果。

(a) 擲得 4：合適結果 = $\{4\}$，1 個
$P(4) = \frac{1}{6}$

(b) 擲得奇數：合適結果 = $\{1,3,5\}$，3 個
$P(\text{奇數}) = \frac{3}{6} = \frac{1}{2}$

答案：(a) $\frac{1}{6}$ (b) $\frac{1}{2}$
例題 3：樹形圖
同時拋兩枚硬幣。求兩枚硬幣都出現正面的概率。
▶ 顯示解答
所有可能結果：正正、正反、反正、反反（4 個）

合適結果（兩枚都是正面）：正正（1 個）

$P(\text{兩正}) = \frac{1}{4}$

答案：$\frac{1}{4}$
例題 4：一正一反
同時拋兩枚硬幣。求恰好出現一個正面和一個反面的概率。
▶ 顯示解答
所有可能結果：正正、正反、反正、反反（4 個）

合適結果（恰好一正一反）：正反、反正（2 個）

$P(\text{一正一反}) = \frac{2}{4} = \frac{1}{2}$

答案：$\frac{1}{2}$
例題 5：期望次數
一個硬幣被拋 500 次。預期有多少次出現正面？
▶ 顯示解答
正面概率 $p = \frac{1}{2}$，試驗次數 $n = 500$

期望次數 $= np = 500 \times \frac{1}{2} = 250$

答案：250 次
例題 6：期望值
一個遊戲規定：擲骰子，若擲得 6 獎 \$10，否則付 \$2。參與這個遊戲是否公平？
▶ 顯示解答
$P(\text{擲得6}) = \frac{1}{6}$，$P(\text{否則}) = \frac{5}{6}$

期望回報 $= 10 \times \frac{1}{6} + (-2) \times \frac{5}{6} = \frac{10}{6} - \frac{10}{6} = 0$

期望值 = 0，故遊戲是公平的。

答案：公平（期望值 = 0）
