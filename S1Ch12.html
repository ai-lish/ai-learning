Ch12 全等三角形

SSS · SAS · ASA · AAS · RHS

📐 12.1 全等三角形
全等（≅）：形狀和大小完全相同的三角形，疊放後完全重合。
五個全等條件
SSS
三邊分別相等
Side-Side-Side
SAS
兩邊及其夾角相等
Side-Angle-Side
ASA
兩角及其夾邊相等
Angle-Side-Angle
AAS
兩角及一邊相等
Angle-Angle-Side
RHS
直角三角形：斜邊 + 其中一股相等
Right Angle-Hypotenuse-Side
🧠 記憶口訣：
• SSS — 三邊都要量
• SAS — 夾角在中間，兩側要相等
• ASA — 夾邊在中間，兩側要相等
• AAS — 任意兩角 + 任意一邊
• RHS — 只用於直角三角形，斜邊一定要
📏 12.2 對應頂點與標記
寫全等三角形時，對應頂點必須按順序標記。
△ABC ≅ △DEF
對應頂點：A↔D、B↔E、C↔F
對應邊：AB=DE、BC=EF、CA=FD
對應角：∠A=∠D、∠B=∠E、∠C=∠F
📌 標記方法：
• 相同長度的邊用相同數目嘅短線標記
• 相同度數的角用相同數目嘅弧線標記
• 例：AB 和 DE 都標 1 條短線 → AB = DE
📐 12.3 應用：證明全等
解題步驟
Step 1：找出兩三角形
Step 2：列出已知相等部分（邊/角）
Step 3：選擇適合的全等條件
Step 4：寫出對應頂點配對
Step 5：結論 △ABC ≅ △DEF
Example：
如圖，AB = AD，AC 是公共邊，∠BAC = ∠DAC
→ SAS 條件：AB=AD、AC=AC、∠BAC=∠DAC
→ △ABC ≅ △ADC（對應頂點：B↔D、A↔A、C↔C）
SSS 條件
如圖，AB = AD，BC = CD，AC 是公共邊。△ABC 和 △ADC 全等嗎？用什麼條件？
提示：△ABC 三邊 = △ADC 三邊（全等）
SAS 條件
△ABC 中，AB = 8cm，BC = 6cm，∠B = 60°。若 △DEF 中，DE = 8cm，EF = 6cm，∠E = 60°，兩三角形是否全等？用什麼條件？
提示：夾角在兩邊之間 → SAS
ASA / AAS 條件
如圖，AB // CD，O 是交點。已知 ∠ABO = ∠CBO，AO = DO。△ABO 和 △CBO 全等嗎？用什麼條件？
提示：考慮 ASA 或 AAS
RHS 條件
△ABC 和 △DEF 均為直角三角形，∠C = ∠F = 90°。已知 AB = DF（斜邊），BC = DE（一股）。兩三角形全等嗎？用什麼條件？
提示：直角三角形專用 RHS
