# 20260624_S5_T3_P2_DEPLOY_V1

## 1. 背景

Deploy 2025-26 S5 第三學期數學科卷二到 `ai-learning` 考試專區，讓學生可免登入查看 45 條選擇題、答案及詳解。

## 2. 現況分析

- 入口：`exam/index.html` 目前有 4 張既有卡片。
- 模板：`exam/2025-26-s5-term2/index.html`、`p1.html`、`p1/q1.html` 提供免登入靜態頁模式。
- Phase 1 輸出：`exam/2025-26-s5-term3/solutions.md` 及 `solutions-answers.json` 已有 45 題 canonical answers/solutions。
- 原 plan v2 的問題：不能 publish raw PDF；不能以 raster PNG 作 published figures；不能沿用 `pdf2image`/PIL PNG splitter 作 deploy 依賴。
- 私隱風險：PDF cover 有原校名、教師名及學生識別欄位；published HTML 必須移除。

## 3. 使用者要求整理

1. 建立 2526 S5 Term3 Paper 2 landing、overview 及 45 條逐題頁。
2. 所有學生頁面免登入可用，不載入 auth widget。
3. 不 publish PDF、raw page PNG、學校名、教師名或學生資料。
4. 代數用 MathJax LaTeX；圖像用 inline SVG。
5. Q11/Q19/Q26/Q37/Q39/Q40 顯示 figure gate banner。
6. `exam/index.html` 只新增一張卡，不改動既有 4 張卡。

## 4. 產品原則

- 主要學生流程免登入可用。
- 登入不作本功能依賴。
- 不破壞現有考試工具和既有卡片。
- 不新增公開秘密、PDF、學生私隱資料。
- GitHub Pages 路徑使用相對路徑，保留 `/ai-learning/` base path。

## 5. 實作範圍

可以修改或新增：

- `exam/index.html`
- `exam/2025-26-s5-term3/index.html`
- `exam/2025-26-s5-term3/p2.html`
- `exam/2025-26-s5-term3/p2/q1.html` 至 `q45.html`
- `exam/2025-26-s5-term3/solutions.md`
- `exam/2025-26-s5-term3/solutions-answers.json`
- `scripts/build_s5_t3_p2_pages.py`

不應修改：

- 既有 4 張 `exam/index.html` 卡片的內容和連結
- `exam/practice.html` loader
- raw PDF 或 raster extracted page images
- 與本任務無關的首頁、登入、學生紀錄、老師工具

## 6. 具體任務

1. 從 Phase 1 canonical solutions/answers 生成 45 條逐題頁。
2. 用 sanitized OCR/PDF-extracted 題目文字，移除學校名、教師名及學生識別欄位。
3. 將數式寫成 MathJax `\(...\)` 或 `$$...$$`。
4. Q11/Q19/Q26/Q37/Q40/Q41 使用 hand-authored inline SVG。
5. 其他有圖題使用 inline SVG placeholder，文字說明需可見。
6. Q11/Q19/Q26/Q37/Q39/Q40 加上 banner：`⚠️ 答案 verified math, figure SVG 須手動校對`。
7. 建立 term landing、P2 overview、45 題 grid 和答案表。
8. 在 `exam/index.html` 新增一張「2526 S5 第三學期 數學科 卷二」卡。
